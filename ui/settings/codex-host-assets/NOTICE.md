# CodexHost Agent identification assets

These unmodified Agent identity assets come from the public CodexHost v0.16.1 release:
https://github.com/BytePioneer-AI/codex-host/tree/v0.16.1

`codex.png` is `packages/renderer-extension/src/assets/codex-agent.png`.
The other files are the icons referenced by `packages/adapters/<agent>/manifest.json`,
renamed to the adapter ID. `kiro-cli.svg` is originally `assets/kiro-agent.svg`;
the remaining adapter icons are originally `assets/icon.svg` or `assets/icon.png`.

GPL-3.0 text in `COPYING-GPL-3.0`. Source assets and names remain attributed to
the CodexHost contributors and their respective brand owners. These marks identify
compatible products; no endorsement or ownership of these marks is claimed.

Palboo's independent preview UI uses these assets with isolated example state.
The catalog is not a probe of installed Agents and does not install or switch them.
