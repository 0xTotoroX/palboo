# ui/settings/ — React 配置网页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

设置统一使用界面、功能、系统三组及独立子页（开发来源仅开发版可见），不提供简易/详细切换；640px及以下使用“分类 / 当前页”单行入口，展开同一份按分类分组的页面目录，每组两列直接选页；641px起保持侧栏，641–900px收窄至128px。菜单支持方向键/Home/End、Esc、外点与Tab离开关闭，跨断点接续焦点。所有表单只挂载一份，分类仅隐藏节点，不重置配置或草稿；关闭抽屉保留内部滚动位置。分类记忆保存在当前标签页 sessionStorage，兼容旧分类键；旧模式值忽略且不清除，旧简易/总览链接进入常用开关。阅读位置按子页暂存，功能与布局请求沿用原服务、修订校验和保存队列。

成员清单：

- `performance-settings.tsx`：系统中的性能与开关页面；独立修订保存 Codex 集成与监测偏好，页面可见时每5秒采样，写入期间拒绝旧读取覆盖；后台物理内存/单核CPU与宿主页整体指标分开标注，不将整页开销归因 Palboo。隐藏页面停止请求，表单保持挂载。
- `performance-monitor.tsx` / `performance-monitor.css`：性能页监视窗跟随现有设置深浅主题，去除重复状态、采样机制和装饰性小字；必要指标口径放在标题悬停提示，显示后台 CPU 环形仪表、CPU/物理内存 SVG 走势、已测工作条与整页长任务轨迹；容器窄于480px时上下排列。只消费页面样本，不新增请求、定时器或动画循环；减少动态效果关闭数值过渡。
- `performance-history.ts`：性能样本与纯数值历史，最多60点且不超过5分钟；重复/过期样本不追加，后台进程变化重置，缺测与时间间断分段绘制；关闭监测清空，不持久化。

- [main.tsx](main.tsx)：Tom Modern 统一入口、共享功能开关、唯一任务状态与分类容器；组合现有模块及其只读预览快照，表单保持单份挂载；布局页锚点位于包含预览的 main，首次打开不跳过预览，切页阅读恢复与字段定位仍由 settings-outline 管理；常规配置直接显示，导航按640px断点布局：窄屏单行分组页面选择器，中等宽度窄侧栏，宽屏左侧纵排目录；共用单份导航与表单；常用开关页不挂载预览，直接显示七个功能开关；功能开关旁不重复提供打开按钮；版本位于页面末尾，不覆盖内容，不持有任务或模型业务。
- [settings-overview.tsx](settings-overview.tsx)：按承载与功能组织只读总览；显示已保存的功能归属、承载主题与布局、生成配置、看板分组计数及当前/常用模型和预设，字号只显示一位小数，属性链接定位对应设置控件并展开折叠项；分类可见时读取现有 API，不直接修改配置或打开功能。
- [settings-outline.tsx](settings-outline.tsx)：单份分组目录在侧栏/窄屏展开菜单间复用、焦点与键盘操作、浏览器历史、旧锚点按字段分流、阅读位置保存及 Dev 来源挂载；支持分类/属性锚点，等待异步表单就绪后展开并聚焦目标；重新挂载前保留外部注入的 Dev 节点，避免热更新丢失来源入口。
- [settings-disclosure.tsx](settings-disclosure.tsx)：保留的原生details展示兼容组件，当前常规配置已改为直接显示；支持强制展开与用户折叠状态接续；在布局阶段暂存/还原DOM开合，不用异步toggle事件覆盖用户状态，不卸载子内容。
- [settings-controls.tsx](settings-controls.tsx)：共用设置行、功能开关、反馈及自动/手动保存表单；只有输入控件失焦触发自动保存，操作按钮与导航失焦不重交旧快照；保存反馈跟随触发编辑的设置项，自动保存成功短暂显示，失败/冲突就近保留并可重试；抽屉继续使用已有底部操作区，手动保存沿用原表单及队列，在途新编辑不误报成功。
- `settings-feedback.tsx`：反馈锚点与临时展示槽；将反馈放到设置行后，不移动输入或改变表单归属，目标被移除时回到原位置；只管理呈现，不持有保存服务。
- [next-settings.tsx](next-settings.tsx)：下一步依次显示操作设置、生成/方向与常用提示词；名称、内容和删除并列为紧凑行，长内容自然增高；仅页面外层隐藏原节点保留草稿；共享模型配置移入model-settings，不复制表单。
- [model-settings.tsx](model-settings.tsx)：系统中的唯一共享模型服务/凭据表单，直接显示常规参数及协议；环境变量名与高级生成参数统一在“高级设置”抽屉中编辑；局部模型列表、密钥显示与草稿保留，调用共用SettingsEditor。模型候选使用共用 SuggestionInput，箭头/方向键主动读取已保存连接的列表，展开显示全部候选、输入过滤；读取失败或空列表仍可手填。未保存连接不读旧候选，修订号及请求序号隔离迟到结果；展开不提交草稿，保留原失焦保存。连接测试的保存中/等待耗时/成功/失败结果直接显示在按钮下方，不依赖页顶通知；保存失败不测试旧配置，编辑或修订变化清除旧结果，在途配置变更不显示为当前连接成功。
- [model-credentials.tsx](model-credentials.tsx)：已存 API 密钥显示配置状态与更换入口，不回读原值；新草稿非空才提供眼睛，取消保留旧密钥。删除仅在高级连接设置显示，原生 dialog 默认聚焦取消，确认后走独立清除补丁；失败保留状态，确认修订过期时拒绝删除。
- [direction-settings.tsx](direction-settings.tsx)：主页面统一展示生成时机、方向来源和有序名称列表；整行原生拖动排序显示插入线，落点确认才保存，取消或未改变顺序不写入，保留 Alt+上下方向键及移动后的焦点，行内只显示移除按钮；方向库为标题右侧的轻入口，选择方向使用独立小面板，Jev 同意及凭据只在智能模式下直接显示，仍共用模型保存队列。
- [direction-picker.tsx](direction-picker.tsx)：排除已选项的小型分类选择面板，优先可选自定义方向，搜索跨内置和自定义名称/说明；点选只追加已有 ID，编辑留在方向库。支持键盘选择、Esc 返回、外点/移出焦点关闭、上下避让与内部滚动；页面滚动时重新计算避让，入口离开视口后关闭，避免点击入口后的滚动事件误关面板；导航和搜索不触发表单保存。

Bot 资料的置顶组仅在与后续分组之间显示一条分隔线，不显示置顶标题、底色、外框或额外缩进，行内不重复画线；其余分组保留原顺序，共用 botGroups.kind，不把置顶文字带入各功能表面。外观样本背景复用 shared/brand 的 PALBOO 字标，无额外图片请求。

术语管理新增只填名称，任意格式文件经 api.uploadTerminology 原样提交到限定大小的认证上传接口；状态按任务显示并保留重试/移除，只有等待结果且页面可见时刷新。导出仅个人添加/收藏/掌握，重置带词库修订号并明确确认，基础词库保留。Bot 资料标题只显示搜索图标，点击展开短输入、自动聚焦，Esc/关闭清空并恢复焦点。

模型额度、性能开关及 CodexHost 管理操作复用 settings-feedback 的就近锚点；模型分组中的反馈留在固定底部操作区，不改变修订校验或外部环境。

语言位于“外观与字体”表单首行。`language-settings.tsx` 仅按 appearance 修订保存 language，失败保留原选择；main 接收后台快照后同步语言和文档 lang/title。`direction-copy.ts` 只翻译与内置原文完全一致的字段，用户修改保留原文。所有页面共享语言订阅，导航、抽屉和表单不因语言切换重挂载；预览使用稳定ID，示例标题跟随语言但编辑内容和选择保留。`bot-setup-prompt.ts` 提供语义相同的中英文接入说明。Dev 来源脚本使用自身打包后的同一文案目录，并读取设置页语言。
