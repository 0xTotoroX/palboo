# ui/settings/ — React 配置网页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

设置统一使用界面、功能、系统三组及独立子页（开发来源仅开发版可见），不提供简易/详细切换；640px及以下使用“分类 / 当前页”单行入口，展开同一份按分类分组的页面目录，每组两列直接选页；641px起保持侧栏，641–900px收窄至128px。菜单支持方向键/Home/End、Esc、外点与Tab离开关闭，跨断点接续焦点。所有表单只挂载一份，分类仅隐藏节点，不重置配置或草稿；关闭抽屉保留内部滚动位置。分类记忆保存在当前标签页 sessionStorage，兼容旧分类键；旧模式值忽略且不清除，旧简易/总览链接进入功能开关。阅读位置按子页暂存，功能与布局请求沿用原服务、修订校验和保存队列。

成员清单：

- `startup-settings.tsx`：“启动与连接 → 启动行为”的沿用上次/默认收起/默认打开，以及打开时的内/外位置；独立保存 appearance.startup 和 expectedRevision，失败回读，离线及不支持桌面时禁用相关操作；不提交模型草稿、不立即移动当前窗口，旧配置沿用上次状态。

- `performance-settings.tsx`：系统中的性能与开关页面；独立修订保存 Codex 集成与监测偏好，页面可见时每5秒采样，写入期间拒绝旧读取覆盖；后台物理内存/单核CPU与宿主页整体指标分开标注，不将整页开销归因 Palboo。隐藏页面停止请求，表单保持挂载。
- `performance-monitor.tsx` / `performance-monitor.css`：性能页监视窗跟随现有设置深浅主题，去除重复状态、采样机制和装饰性小字；必要指标口径放在标题悬停提示，显示后台 CPU 环形仪表、CPU/物理内存 SVG 走势、已测工作条与整页长任务轨迹；容器窄于480px时上下排列。只消费页面样本，不新增请求、定时器或动画循环；监测关闭时清空历史并移除仪表，不铺空图表或重复开关已表达的停用文案；开启后的等待、失败与断线保留真实状态，减少动态效果关闭数值过渡。
- `performance-history.ts`：性能样本与纯数值历史，最多60点且不超过5分钟；重复/过期样本不追加，后台进程变化重置，缺测与时间间断分段绘制；关闭监测清空，不持久化。

- [main.tsx](main.tsx)：跟随宿主的单个页面标题、共享功能开关及分组表单与预览；品牌和四个页头图标保持。切页保留单份节点、草稿与阅读位置，窄屏使用同一组导航，版本位于页面末尾。
- [settings-overview.tsx](settings-overview.tsx)：按承载与功能组织只读总览；显示已保存的功能归属、承载主题与布局、生成配置、看板分组计数及当前/常用模型和预设，字号只显示一位小数，属性链接定位对应设置控件并展开折叠项；分类可见时读取现有 API，不直接修改配置或打开功能。
- [settings-outline.tsx](settings-outline.tsx)：单份分组目录在侧栏/窄屏展开菜单间复用、焦点与键盘操作、浏览器历史、旧锚点按字段分流、阅读位置保存及 Dev 来源挂载；支持分类/属性锚点，等待异步表单就绪后展开并聚焦目标；重新挂载前保留外部注入的 Dev 节点，避免热更新丢失来源入口。
- [settings-disclosure.tsx](settings-disclosure.tsx)：保留的原生details展示兼容组件，当前常规配置已改为直接显示；支持强制展开与用户折叠状态接续；在布局阶段暂存/还原DOM开合，不用异步toggle事件覆盖用户状态，不卸载子内容。
- [settings-controls.tsx](settings-controls.tsx)：共用设置行、功能开关、反馈及自动/手动保存表单；只有输入控件失焦触发自动保存，操作按钮与导航失焦不重交旧快照；保存反馈跟随触发编辑的设置项，自动保存成功短暂显示，失败/冲突就近保留并可重试；抽屉继续使用已有底部操作区，手动保存沿用原表单及队列，在途新编辑不误报成功。
- `settings-feedback.tsx`：反馈锚点与临时展示槽；将反馈放到设置行后，不移动输入或改变表单归属，目标被移除时回到原位置；只管理呈现，不持有保存服务。
- [next-settings.tsx](next-settings.tsx)：下一步依次显示操作设置与生成/方向；常用语由 quick-prompt-settings.tsx 独立管理；正文在前、短名称选填，长内容自然增高，删除操作靠右；仅页面外层隐藏原节点保留草稿；共享模型配置移入model-settings，不复制表单。
- [model-settings.tsx](model-settings.tsx)：系统中的唯一共享模型服务/凭据表单，直接显示常规参数及协议；环境变量名与高级生成参数统一在“高级设置”抽屉中编辑；局部模型列表、密钥显示与草稿保留，调用共用SettingsEditor。模型候选使用共用 SuggestionInput，箭头/方向键主动读取已保存连接的列表，展开显示全部候选、输入过滤；读取失败或空列表仍可手填。未保存连接不读旧候选，修订号及请求序号隔离迟到结果；展开不提交草稿，保留原失焦保存。连接测试的保存中/等待耗时/成功/失败结果直接显示在按钮下方，不依赖页顶通知；保存失败不测试旧配置，编辑或修订变化清除旧结果，在途配置变更不显示为当前连接成功。
- [model-credentials.tsx](model-credentials.tsx)：已存 API 密钥显示配置状态与更换入口，不回读原值；新草稿非空才提供眼睛，取消保留旧密钥。删除仅在高级连接设置显示，原生 dialog 默认聚焦取消，确认后走独立清除补丁；失败保留状态，确认修订过期时拒绝删除。
- [direction-settings.tsx](direction-settings.tsx)：主页面统一展示生成时机、方向来源和有序名称列表；整行原生拖动排序显示插入线，落点确认才保存，取消或未改变顺序不写入，保留 Alt+上下方向键及移动后的焦点，行内只显示移除按钮；方向库为标题右侧的轻入口，选择方向使用独立小面板，Jev 同意及凭据只在智能模式下直接显示，仍共用模型保存队列。
- [direction-picker.tsx](direction-picker.tsx)：排除已选项的小型分类选择面板，优先可选自定义方向，搜索跨内置和自定义名称/说明；点选只追加已有 ID，编辑留在方向库。支持键盘选择、Esc 返回、外点/移出焦点关闭、上下避让与内部滚动；页面滚动时重新计算避让，入口离开视口后关闭，避免点击入口后的滚动事件误关面板；导航和搜索不触发表单保存。
- [direction-library.tsx](direction-library.tsx)：单个右侧抽屉中的“内置方向 / 我的方向”目录，选择条目后进入名称/说明编辑，返回恢复目录焦点与滚动；字段持续挂载，关闭与分级导航不触发保存。后台只读目录确定来源，修改过的内置文案可恢复默认并保留勾选及顺序。无效字段及深链接通过 detail-reveal 事件同步打开对应条目；私有条目名称不进入全局设置搜索。
- [connection-settings.tsx](connection-settings.tsx)：依次展示桌面连接、启动行为、应用更新和运行模式；连接状态就近显示，不重复挂概览卡。断线隐藏旧成功消息，Dev 固定启动时的目标，重连和断开不提交模型表单。
- [use-settings-form.ts](use-settings-form.ts)：模型及两套独立密钥的草稿、修订校验、保存队列及在途编辑合并；记录编辑来源并在请求期间固定反馈位置；大纲、下一步与常用语开关单独提交，不携带其他字段或密钥草稿；删除 API 密钥复用串行队列，仅发送 clearApiKey 与修订号，不携带其他草稿或将删除意图留在自动保存中；导出 SettingsEditor 供展示模块组合。
- [panel-settings.tsx](panel-settings.tsx)：有效旧字段的分区适配；下一步显示及推荐指令点击行为，常用语未独立选择模式时兼容继承、按窗口的字体族、跟随来源、比例及固定字号、侧栏宽度以整数显示和提交，仅读取/聚焦不改写已有小数几何；桌面置顶逐项保存；旧 fontOffset 作为大纲与下一步的兼容回退。不再编辑旧 dockLayout/popoutLayout、位置或主题。
- [feature-settings.tsx](feature-settings.tsx)：唯一主界面形式、每个功能加入主界面或贴边、四功能布局；与工作台共用 resolveFeatureLayout 读取旧布局，嵌套布局显示为自定义分栏、预设重排保留全部叶子功能，通过 main-layout 校验原快照后保存，未读取配置前禁用操作。
- [surface-settings.tsx](surface-settings.tsx)：功能位置与布局、主题、字体、尺寸与窗口、贴边位置直接分组显示；管理四种形式各自主题及贴边屏幕/位置；屏幕可显式跟随 Codex，保留自动选择与固定屏幕及断开屏幕的选择，写入带 revision 校验。
- [model-control-settings.tsx](model-control-settings.tsx)：模型快切开关、分类状态与串行修订保存，聚焦及轮询回读外部变更，写入期间不被旧读取覆盖；冲突重新读取但不自动重放，失败保留编辑草稿；不持有位置或主题。
- `model-organization.tsx`：右侧抽屉固定顶部模型/厂家搜索与分组筛选，列表独立滚动；勾选后固定底部批量操作栏，通过模式选择纠正厂家/移动/恢复自动，取消选择即收起且保留各模式草稿；保留自定义组增删改名。共用列表排序管理组间/组内顺序，保留未显示及暂不可用模型的位置；搜索期间禁用排序，避免不完整列表含义不明。厂家候选使用 SuggestionInput，仍可自填并显式应用；同名模型显示完整 ID，不改常用与预设。
- `settings-sortable-list.tsx`：方向与模型管理共用的原生拖动/Alt+上下排序、插入线、取消和焦点接续；不添加布局包装层，不持有保存服务。调用方保留修订与保存队列，子集排序只替换对应位置。
- [task-settings.tsx](task-settings.tsx)：设置实际看板的合并/完全展开视图及分组；viewMode经任务修订保存并同步所有承载和预览，默认合并。保存/新增图标提供明确无障碍名称，失败保留草稿；同步授权/列表界面保留源码但不挂载。
- [dev-sources.js](dev-sources.js)：Dev 监督进程注入的来源、资源确认及 worktree 切换；来源以单选目录列表常驻显示，分支与路径各出现一次，不显示提交/资源哈希；切换按钮靠右并显示加载动画与阶段状态，刷新后核验实际来源和资源再确认成功；临时目标在发送请求前写入当前标签页，Vite 提前重载不会把旧文档取消请求误判为交接失败；重载后重新核对实际来源与资源，服务明确拒绝时清除目标，减少动态效果关闭动画，失败保留原因。新版移入开发分类，旧 worktree 继续使用顶部独立入口，不进入正式页面。
- [api.ts](api.ts)：认证请求、错误和 SSE 状态订阅，共用 ../shared/contracts.ts；本轮首个有效快照到达才恢复在线，不把响应头视为状态就绪；普通入口根据认证状态跳转 Dev 统一页。
- [styles.css](styles.css)：Tailwind v4、语义主题映射、搜索和保留的旧总览样式；只扫描本目录，不注入宿主。
- [settings-layout.css](settings-layout.css)：中性首帧回退、共用导航与表单布局；实际颜色/几何由宿主变量覆盖。640px以下为单行分类入口，641–900px侧栏128px，宽屏180px；内容最大760px。独立选择框与数字框等宽右对齐，外观页未分组字段与分组内字段保持对齐，预览顺序不变；正文标题不增加装饰；界面/功能/系统分类文字右下侧保留4px宿主强调色点。
- [settings-controls.css](settings-controls.css)：按钮、输入框、选择器、开关的统一高度、微圆角、中性焦点与禁用态；包含方向库目录/单条编辑层级的主题和控件样式；设置页的独立 NativeSelect 与数字框共用等宽控件列，组合控件内部保留紧凑尺寸；菜单与选择框等宽，原生菜单、自由输入候选、方向选择面板、主题与窄屏目录共享 settings-menu-surface，明暗主题分别取值；材质控件右对齐，选择液态后在同一选择框内显示Clear星星，主题色实心为Clear、中性色空心为Regular；不另加变体下拉或强调底块，保留至少28px命中区域；原生菜单和分段选中表面分别由 components/ui/native-select.css 与 segmented-group.css 共用，支持 base-select 时定制菜单和选项，原生键盘、点击、取消、禁用及 change 事件不变，不支持时保留系统菜单。自由输入候选和搜索弹层沿用同一菜单样式。Dev 来源因 Shadow DOM 隔离，在 dev-sources.js 内以同一语义变量适配，不依赖新版源码文件。
- [settings-preview.tsx](settings-preview.tsx)：设置预览入口；任务、模型和Bot使用当前本地快照，布局与外观页复用同一渲染器及已有标题操作槽，分栏正文限定在承载高度内滚动并保持透明，不再重复铺设底色。下一步、大纲和术语使用合成内容体现表现偏好，不读取真实聊天或调用模型。模型服务摘要按有效内容定高，整体界面预览保持16:9；布局页单屏靠近取景，移向副屏时沿原摄像几何让出双屏空间。网站入口从WebLibrarySettings同一只读快照传入，不重复请求或打开真实页面。
- `feature-preview.tsx`：Shadow DOM内复用实际ProjectedContent、Board、BotsView、TerminologyView。current模式复制任务内容、分组、视图模式与Bot目录/分组/顺序/头像/隐藏状态及最近回复；没有数据就显示加载、空态或错误，不以示例冒充。Bot运行状态不由名单推测；已有回复可显示追问入口，仅填入预览草稿，不伪造当前聊天调用。example模式及术语样本默认使用shared/demo-state；可选example只在示例模式替换投影、任务适配器、术语、Bot及回复／动作和大纲定位回调，current模式忽略它；exampleBoardViewMode可为网站选择完全展开，默认仍合并。active默认为true，隐藏预览时释放正文术语标注引擎并收回浮卡。所有点击只改内存，任务预览禁用轮询；完全展开预览沿用真实窄栏规则，纵向显示全部组，标题操作保持可见；嵌入布局预览时保留真实窄栏适配并使用外层标题操作槽，避免双标题和重复内边距。

功能开关是唯一总开关页，包含大纲、下一步、常用语、术语释义、任务看板、模型切换、Grok Bot、提示词优化与CodexHost九项。聊天测速移入模型切换页，与额度显示并列，保留独立tokenMeterEnabled及原保存队列，旧测速锚点可定位到新位置。模型、术语和CodexHost继续由原组件持有请求/修订，通过FeatureSwitch的portalTarget把单份开关呈现到统一位置；相关读取仅在总开关或本功能页可见时进行，反馈跟随原控件。各子页移除重复启用行；额度显示、聊天测速、自动同步等具体选项保留。模型分组是Palboo自有管理，使用右对齐轻入口，不包装成嵌套分组卡片；抽屉、草稿与键盘行为保持。搜索抽屉优先使用已有稳定包装ID，避免预先加载词库后生成临时入口地址。

main.tsx 从认证 state/SSE 的 systemLanguage 解析“跟随系统”，与原生/工作台一致，浏览器首选语言不覆盖后台结果。预设 deep link 在 ChatGPT 内打开完整设置并直达既有抽屉，管理文案与共享语言同步。

主界面位置、主界面布局和当前预设在同一外框内各占一行，布局与预设的下拉框等宽右对齐；当前预设选择直接应用，包含顶部／左侧内置预设和已保存的命名预设；管理入口置于“主界面”标题右侧，复用 SettingsDrawer 紧凑触发器，不占用字段列。管理抽屉支持通用/侧栏推荐/浮层推荐/桌面推荐；名称与标记草稿共用原修订，冲突/失败保留，取消接收远端。预设为共享目录，各形式布局独立；当前预设按实际布局匹配。

use-host-appearance 分别使用宿主 primary/navSelected/segmented/switchOn 等语义颜色，普通导航和分段文字使用正文色；开关、链接、Clear 星星与焦点按各自角色使用强调色，侧栏分类标题按用户选择保留4px宿主强调色点，正文不加装饰。旧自定义强调色不参与显示。主界面标题与预设管理入口保持中轴对齐，入口使用中性弱化文字；窄屏字段沿用标签在上、控件在下。Bot 资料标题行去除通用标题下边距，使标题与刷新按钮保持中轴对齐。

模型设置首读不受标签页可见性影响，后续轮询只在可见页面串行读取；焦点/可见性变化复用同一读取入口，慢响应不被周期性请求作废。写入继续使用原串行队列与完成后回读。

大纲与提示词优化的介绍位于各自预览之后；提示词优化预览与其他预览同在 settings-body 的首部，保持独立挂载和本地草稿，不嵌在介绍之后的表单列。

use-host-fonts 是 shared/host-fonts 的 React 文档适配器，settings/api 提供认证 HostFontSource，供设置与独立窗口入口共用；有效字体族未变时不重复加载，销毁回收自有字形。字体与字号表单、外观修订和保存范围不变。

- `web-library-settings.tsx` / `web-library-settings.css`：网站功能开关、列表增删改/搜索/排序及独立修订；功能预览固定在页面标题之后、配置之前。预览复用真实 SitesView，仅在内存操作；onSnapshot 与 previewActive 向布局/外观共享一次读取结果。配置先显示文件夹列表，再显示网站列表，细节表单复用保留草稿的共用抽屉。
- `reader-folder-settings.tsx`：多个笔记文件夹的添加/命名/编辑/移除与独立打开；检测到的 Obsidian 名单和系统选择器只填草稿，保存完整 folders 数组并校验原修订；关闭/切页/错误保留草稿，切换编辑对象前确认丢弃。附件授权属于各自文件夹，移除入口不删除原文件；旧单目录配置继续可读写。
- `reader.html`：独立阅读网页构建入口，由 reader 服务单独提供，不复用设置页认证。

本地笔记设置支持 Obsidian 已登记目录及系统“选择文件夹”。原生选择器只返回草稿路径，取消不变，点击保存才通过独立修订授予读取。目录输入继续支持普通 Markdown；设置 ?open=sites 直达该页，不保存草稿。
