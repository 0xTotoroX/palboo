# ui/surfaces/edge/ — 贴边窗口

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `main.ts`：共享贴边标签、稳定视口内的功能挂载、原生几何/scene-ready 确认、悬停及退出生命周期；收起和换标签保留挂载与草稿；观察活动视图及头部的自然尺寸并上报宽高，收放动画期间延后测量。
- `styles.css`：固定图标导航、窄空间换行及展开布局，不参与原生轮廓缩放。

每个功能拥有独立的顶栏操作位置，随标签显隐与 owner 一起回收；按钮操作仍由功能视图提供。模型使用该位置对齐Fast及思考强度表头，模型正文不另占表头行。

收起入口不绘制圆点，展开头部使用共享图标库的功能入口（18px图形、28px点击区、4px间距），选中项用明暗区分，无胶囊底色；名称通过悬停和aria-label提供、当前功能提供的操作；窄空间自然换行并计入头部高度，不挤压模型Fast／思考强度列；不显示手动收起按钮，保留 Esc。悬停约 450ms 后收起，编辑、按住或业务操作期间保持展开；原生遮罩、跨屏幕和全屏空间由既有后台窗口管理。主题与显示器/边缘/位置由设置页管理，不进入功能模块。

[PROTOCOL]: 结构、职责或接口变化时更新本文；父级描述受影响时同步父级地图。

模型功能以420px名称预算提供稳定自然宽度标记，高度按实际名称列宽和预设换行测量；名称列宽拖动期间不改变原生外框，松手后再适配高度。达到屏幕可用高度才由整体常用区滚动。刷新位于“所有”目录的关闭按钮旁，沿用模型功能的显示规则。

贴边标签从原 feature state 读取统一字体偏好和快照；原生几何事件不覆盖字体，内容仍由 feature-session 统一适配。

显示器可在设置页显式选择跟随 Codex，原生层按当前连接宿主的窗口坐标选择屏幕；拖动贴边位置保留跟随，固定屏幕选择与已有偏好兼容。

- `tabs.ts`：从shared/features读取六功能图标与名称，单击直接切换，支持拖动及 Alt+左右方向键排序；串行保存顺序与最后选中项，失败提示并恢复确认状态，外部冲突不覆盖；暂时不可用的功能保留顺序和选择偏好，新功能追加。自动热重载在保存期间等待，换标签不重建业务视图。

main 从 feature state 的 edgeTabs/edgeTabsRevision 读取偏好，经 features/edge-tabs 以 expected 原值保存到 surfaces.json；原生几何更新同步可见内容矩形，任务详情以该矩形限定位置与滚动范围，不再使用整个透明 WebView 视口。
