# reader/ — 独立笔记网页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

- `api.ts`：独立reader凭证按文件夹ID保存在标签会话中并立即从URL移除，所有请求携带文件夹身份；认证读取与同源编辑/设置跳转，不访问设置token；区分冲突、连接中断和读取失败。
- `main.tsx`：目录/搜索/正文、候选选择、反链/文章目录、阅读位置和历史；可折叠侧栏内显示库名/多文件夹切换、刷新与笔记文件夹设置，切换前等待保存，URL和阅读位置按文件夹隔离，无全宽顶栏或只读标记；编辑中不被刷新替换，导航先保存。
- `editor-view.tsx`：正式阅读器与介绍页共用的纯界面编辑器，接收草稿、保存状态及显式回调，不读取凭证或调用API。
- `editor.tsx`：明确进入 Markdown 编辑，700ms停顿后串行自动保存；中文输入法组合中不保存，处理在途新输入、Cmd/Ctrl+S、失败重试、冲突复制/重读和离页保护；草稿仅存内存，不自动覆写外部版本。
- `spreadsheet-view.tsx`：纯表格与工作表/分页控件，共用正式数据和隔离示例，单元格仍作为文本。
- `spreadsheet.tsx`：工作表切换、表格滚动和100行分页，单元格作为纯文本显示；显示文件中已保存的公式结果，不计算/编辑工作簿。
- `markdown.tsx`：不含请求的安全 GFM、wiki AST、别名/锚点/callout渲染，图片和外链通过显式适配器接入；无图片适配器时只显示替代文字，不执行HTML/脚本/Obsidian插件。
- `picture.tsx`：正式阅读器的认证图片、显式加载外部图片与放大查看；不进入介绍页。
- `tree.tsx`：共享文件夹/文档/表格图标，关闭目录不挂载子节点；文件夹、下划线前缀优先，数字自然排序。
- `style.css`：独立阅读/编辑/表格样式与窄屏目录切换，语义颜色跟随宿主；侧栏收起保留44px展开入口，状态只在会话保存。

[PROTOCOL]: 变更时更新此头部，然后检查 AGENTS.md。
