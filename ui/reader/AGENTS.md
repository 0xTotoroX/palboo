# reader/ — 独立笔记网页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

- `api.ts`：独立reader凭证按文件夹ID保存在标签会话中并立即从URL移除，所有请求携带文件夹身份；认证读取与同源编辑/设置跳转，不访问设置token；区分冲突、连接中断和读取失败。
- `main.tsx`：目录/搜索/正文、候选选择、反链命中定位、阅读位置和历史；搜索命中含代码和属性，展开折叠祖先后定位，导航统一经过保存门禁；可折叠侧栏内显示库名/多文件夹切换、刷新与笔记文件夹设置，切换前等待保存，URL和阅读位置按文件夹隔离，无全宽顶栏或只读标记；编辑中不被刷新替换，导航先保存。
- `navigation.tsx`：无请求的侧栏尺寸、路径面包屑与原生 dialog 快速切换器；宽度 180–520px、默认232px，拖动/方向键调整、双击/Home恢复；正式网页通过localStorage保存，介绍页不传存储键；窄屏保留正文空间，暂时约束渲染宽度不覆盖偏好。Quick Switcher按本库标题和路径筛选、最多显示100条，支持方向键/Enter/Esc与焦点恢复。
- `outline.tsx`：共用标题身份的目录视图，正文可用宽度达到920px时移到右侧、可选择常驻；主入口从真实滚动计算当前标题，窄屏保持可折叠目录。
- `properties.tsx`：使用yaml核心schema只读解析Frontmatter，键值列表与tags胶囊；禁用别名展开，错误/未知类型显示原文，不丢失正文。
- `search.tsx`：纯文本搜索标记，供代码、属性及路径复用，不改DOM或读取文件。
- `editor-view.tsx`：正式阅读器与介绍页共用的纯界面编辑器，接收草稿、保存状态及显式回调，不读取凭证或调用API。
- `editor.tsx`：明确进入 Markdown 编辑，700ms停顿后串行自动保存；中文输入法组合中不保存，处理在途新输入、Cmd/Ctrl+S、失败重试、冲突复制/重读和离页保护；草稿仅存内存，不自动覆写外部版本。
- `spreadsheet-view.tsx`：纯表格与工作表/分页控件，共用正式数据和隔离示例，单元格仍作为文本。
- `spreadsheet.tsx`：工作表切换、表格滚动和100行分页，单元格作为纯文本显示；显示文件中已保存的公式结果，不计算/编辑工作簿。
- `markdown.tsx`：不含请求的安全 GFM、wiki AST、别名/锚点、按类型着色及 +/- 折叠 Callout、==高亮==、行内标签和代码复制渲染，图片和外链通过显式适配器接入；无图片适配器时只显示替代文字，不执行HTML/脚本/Obsidian插件。
- `picture.tsx`：正式阅读器的认证图片、显式加载外部图片与放大查看；不进入介绍页。
- `tree.tsx`：共享文件夹/文档/表格图标，受控展开集合提供全部折叠和定位当前笔记，关闭目录不挂载子节点；文件夹、下划线前缀优先，数字自然排序。
- `style.css`：独立阅读/编辑/表格样式、12px 层级引导与长名称换行、按正文可用宽度切换的常驻目录，以及窄屏目录切换，语义颜色跟随宿主；侧栏收起保留44px展开入口，开合只在会话保存，展开宽度单独持久化。

[PROTOCOL]: 变更时更新此头部，然后检查 AGENTS.md。
