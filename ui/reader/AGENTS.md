# reader/ — 独立笔记网页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

- `preferences.ts`：侧栏宽度/固定偏好的认证加载与串行防抖保存，晚到读取不覆盖新编辑；未确认写入暂存本机，刷新后重试，成功后清除；旧浏览器值仅作首次迁移与失败回退，无存储键的介绍页不请求。
- `api.ts`：独立reader凭证按文件夹ID保存在标签会话中并立即从URL移除，所有请求携带文件夹身份；认证读取与同源编辑/设置跳转，不访问设置token；区分冲突、连接中断和读取失败。
- `main.tsx`：目录/搜索/正文、候选选择、反链命中定位、阅读位置和历史；单一搜索框合并本库标题/路径即时匹配与全文检索（`Cmd/Ctrl+O`/`K`聚焦同一搜索框，侧栏收起时临时覆盖展开，支持方向键/Enter/Esc与清除），搜索命中含代码和属性，展开折叠祖先后定位，导航统一经过保存门禁；可折叠侧栏头部集成库名/多文件夹切换、定位当前笔记、全部折叠、刷新与笔记文件夹设置，正文顶栏合并可点击文件夹面包屑与编辑入口，无全宽顶栏或只读标记；编辑中不被刷新替换，导航先保存。
- `sidebar.tsx`：固定/临时侧栏生命周期，响应式切换保留固定意愿，快捷键和抽屉焦点约束/关闭恢复；不改变阅读或草稿。
- `library-navigation.tsx`：共享文件/最近标签、方向键/Home/End与有效最近记录列表；查询时隐藏但不卸载文件树，沿用主入口保存门禁，正式页面/介绍页分别传入已有记录和内存样本。
- `home.tsx`：继续阅读/最近打开与首次文件树，仅保存每个授权文件夹的最近八个有效笔记标识；不持久化正文或凭据。
- `search-state.ts`：标题/路径即时匹配与全文结果合并去重，按笔记身份保持键盘选中，分页与取消旧请求；`search.tsx`继续只负责显示。
- `navigation.tsx`：无请求的侧栏尺寸与可交互路径面包屑；宽度 180–520px（独立网页默认268px，介绍页默认232px），拖动/方向键调整、双击/Home恢复；正式网页通过preferences认证接口保存，兼容localStorage，介绍页不传存储键；窄屏保留正文空间，暂时约束渲染宽度不覆盖偏好；面包屑文件夹段支持点击在目录树展开定位。
- `outline.tsx`：无请求的跟读目录，复用正文标题身份与当前章节标记，作为信息栏内容，不另建正文目录卡片。
- `history.tsx`：阅读页自有历史边界及前进/后退图标；游标与会话上限只保存元数据，刷新后恢复，分支跳转丢弃旧前进分支；原生popstate先经过编辑保存门禁，失败回到原游标，不插入重复历史。
- `information.tsx`：文章目录/反向链接共享信息栏与键盘标签；扣除左侧固定栏后至少1040px时可常驻252px右栏并独立滚动，窄屏复用右侧模态抽屉、关闭恢复焦点；响应式变化保留宽屏开合意愿，不重建正文。介绍页可传示例边界，仍复用同一组件。
- `link-preview.tsx`：内部链接延时悬停/聚焦纯文本摘要；取消迟到请求，最多20项内存缓存，切换来源/索引修订清理；缺失/同名/失败明确反馈。预览不导航或记录最近打开，显式打开才调用原保存门禁；Tab/Alt+↓进入卡片、Esc恢复链接焦点，适配器允许介绍页只用隔离样本。
- `properties.tsx`：使用yaml核心schema只读解析Frontmatter，紧凑可折叠属性卡片、键值列表、tags/aliases胶囊与嵌套对象平铺；禁用别名展开，错误/未知类型显示原文，不丢失正文。
- `search.tsx`：纯文本搜索标记，供代码、属性及路径复用，不改DOM或读取文件。
- `editor-view.tsx`：正式阅读器与介绍页共用的纯界面编辑器，接收草稿、保存状态及显式回调，不读取凭证或调用API。
- `editor.tsx`：明确进入 Markdown 编辑，700ms停顿后串行自动保存；中文输入法组合中不保存，处理在途新输入、Cmd/Ctrl+S、失败重试、冲突复制/重读和离页保护；草稿仅存内存，不自动覆写外部版本。
- `spreadsheet-view.tsx`：纯表格与工作表/分页控件，共用正式数据和隔离示例，单元格仍作为文本。
- `spreadsheet.tsx`：工作表切换、表格滚动和100行分页，成功读取通过onRead回调记入共用最近记录，单元格作为纯文本显示；显示文件中已保存的公式结果，不计算/编辑工作簿。
- `markdown.tsx`：不含请求的安全 GFM、数学AST、wiki AST、别名/锚点、首行一级标题置于属性卡之上、稳定保留正文节点与折叠状态，提供内部链接预览标记，按类型着色及可旋转箭头折叠 Callout、==高亮==、行内标签和带语言栏的代码复制渲染，图片和外链通过显式适配器接入；无图片适配器时只显示替代文字，不执行HTML/脚本/Obsidian插件。
- `code-block.tsx`：共享代码语言栏与逐字源码复制，允许图表复用操作和内容槽；复制反馈定时器随卸载释放。
- `rich-content.tsx`：视口附近懒加载公式/图表引擎，主题上下文不重建正文；图表源码切换/放大对话框、错误回退及取消迟到工作，跟随卸载回收字体样式和Blob URL。
- `math-engine.ts`：本地KaTeX的非信任、限长/限宏渲染；独立网页与介绍页Shadow DOM共用引用计数字体样式，无跨表达式宏。
- `diagram-engine.ts`：本地Mermaid串行渲染、主题语义色解析、源码资源/配置语法预检及SVG输出检查；图表作为Blob图片而非活动HTML插入，临时测量节点始终清理。
- `picture.tsx`：正式阅读器的认证图片、显式加载外部图片与放大查看；不进入介绍页。
- `tree.tsx`：`useTreeExpansion` 受控展开集合提供全部折叠、定位当前笔记与定位文件夹，单行紧凑节点配合完整路径悬停提示，关闭目录不挂载子节点；共享文件夹/文档/表格图标，文件夹、下划线前缀优先，数字自然排序。
- `style.css`：独立阅读/编辑/表格样式、微染色侧栏表面、单行32px目录与层级引导线、右侧目录/反链信息栏、窄屏模态抽屉及链接预览卡片，语义颜色跟随宿主；侧栏收起零占位，顶栏提供目录/搜索及阅读首页，抽屉不推挤正文；固定意愿在会话保存，展开宽度单独持久化。
