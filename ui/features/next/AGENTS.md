# ui/features/next/ — 下一步内容

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `view.js`：createNextView 创建实例级建议列表、预览与悬停/焦点计时器；独立下一步不挂载快捷词，旧工作台兼容模式仍保留；推荐指令支持 direct、hybrid、fill 点击规则、延迟与双击取消，销毁时清理计时器。

只读取投影与临时选中项，通过 command 回调提交操作意图。生成、缓存与输入框草稿保护位于 ui/codex/next.js，模型请求由既有后台执行。共享投影视图和旧工作台适配器复用本模块。

内容更新签名不包含本地预览选择，轮询不重建未变化的建议按钮，也不取消等待中的点击；投影适配层保留键盘焦点和尺寸变化前的预览阅读位置。

建议行使用素净文字样式：前置 18px 折弯箭头复用共享 return SVG 并水平镜像，紧靠内容左侧，以更小间隔连接文字；标题统一使用主文字色和中等字重，摘要较小且弱化，完整指令保持正文对比度。完整预览只显示正文，不重复标题或条目计数，正文左边界与建议文字对齐。常规状态及悬停/预览选中状态均无边框和底色，常用提示词采用独立下划线标签（不改变模型预设样式）：18px圆角、6px/14px内边距、10px间距，跟随宿主明暗与语义颜色，长标签自然换行；末尾添加与铅笔按钮复用18px图形和28px点击区，不增加外层框，键盘焦点保留细线，减少动态效果时关闭状态过渡。标题/摘要开关、字号、阅读及点击规则仍由原配置控制。

[PROTOCOL]: 结构、职责或接口变化时更新本文；父级描述受影响时同步父级地图。

- `drag.js`：推荐条目的原生复制拖放，抓取时读取投影身份、取消点击计时器，显示跟随鼠标的短预览副本；原条目保留，拖放后不追加一次点击。clear 回收监听与临时节点。完整正文由宿主在释放时从当前推荐中读取。

`quick-prompts.js`：默认保留紧凑的下划线快捷标签，expanded 模式为独立常用语显示宽条目和正文预览；末尾添加/铅笔入口和就地名称/正文编辑共用，删除先确认。expanded 标记随重绘保留，编辑态删除操作位于条目右上角且不覆盖文字。草稿、编辑状态与已确认列表存在Reading中，不持久化；关闭编辑不写配置，失败和冲突保留草稿，进行中禁用重复操作，原点击填入/发送规则保持。最多8项，空列表仍能添加。

功能名称统一为“下一步”。推荐列表空闲时所有箭头使用主文字色；仅在鼠标悬停某一条时，将其他条目的文字和箭头保留90%不透明度（键盘焦点项除外），移开即恢复，不随保留的预览选择持续变暗；触屏不模拟悬停，减少动态效果时立即切换。

手动模式空状态在回答已就绪、扫描空闲且关联可用时显示“点击刷新生成建议”；等待回答时不提前提示可生成。首次刷新与已有建议刷新分别使用“生成建议”和“重新生成建议”的可访问名称。
