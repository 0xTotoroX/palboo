内容更新签名不包含本地预览选择，轮询不重建未变化的建议按钮，也不取消等待中的点击；投影适配层保留键盘焦点和尺寸变化前的预览阅读位置。

建议行使用素净文字样式：前置 18px 折弯箭头复用共享 return SVG 并水平镜像，紧靠内容左侧，以更小间隔连接文字；标题统一使用主文字色和中等字重，摘要较小且弱化，完整指令保持正文对比度。完整预览只显示正文，不重复标题或条目计数，正文左边界与建议文字对齐。常规状态及悬停/预览选中状态均无边框和底色，常用提示词采用与模型预设一致的独立微凸标签：18px圆角、6px/14px内边距、10px间距，跟随宿主明暗与语义颜色，长标签自然换行；末尾添加与铅笔按钮复用18px图形和28px点击区，不增加外层框，键盘焦点保留细线，减少动态效果时关闭状态过渡。标题/摘要开关、字号、阅读及点击规则仍由原配置控制。
