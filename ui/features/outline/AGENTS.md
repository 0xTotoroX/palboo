# ui/features/outline/ — 大纲内容

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `view.js`：从大纲投影生成列表，处理编号悬挂对齐、条目及首尾定位按钮；以回调交出定位意图。syncOutlineAvailability 原位更新导航禁用和悬停提示，不替换缓存条目或重置阅读位置。列表项由外层承载，内部原生按钮保留按钮语义与键盘定位。

共享投影视图和旧工作台适配器使用同一实现；历史回复模式提供「跟随最新回答」。原文虚拟卸载时保留已有目录并禁用定位，悬停提示滚动到原文；没有缓存时才显示来源缺失空态，返回最新入口继续可用。聊天解析、重挂载核验及实际定位位于 ui/codex/outline.js；标题拖动与临时放大由 workspace 处理。

大纲与下一步共用无框文字风格和中性细线键盘焦点；每条标题前显示小圆点，悬停/当前位置只加深文字与圆点，不绘制卡片。顶层标题采用 500 字重，子级保持可读文字色并用缩进区分；原文编号保留，圆点与多行标题首行对齐，编号悬挂宽度使用 CSS 像素以兼容页面缩放。

[PROTOCOL]: 结构、职责或接口变化时更新本文；父级描述受影响时同步父级地图。
