# ui/features/model/ — 模型快切内容

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `view.tsx`：默认展示固定模型、固定 CLI 和完整配置预设；四点目录容纳就绪 CLI 的切换/固定、当前 CLI 模型的固定和可展开的推理矩阵。固定项复用带可选 CLI 的预设，已有常用和预设保留，旧预设不猜测来源。跨 CLI 的模型固定项一次请求完成 CLI 切换及模型配置；锁定会话的跨 CLI 动作预先显示「新建聊天」。保留 Fast、列宽、预设编辑和底栏额度/测速。
- `heading.tsx`：提供目录中的推理矩阵表头，按列对齐 Fast 与推理档位；目录刷新、关闭按钮由 view 放入现有容器标题槽。
- `fast-motion.ts`：接收正在执行的操作结果，只管理充电、保持充满、放电视觉时序和取消，不改变模型状态或发起保存。
- `catalog.ts`：快切及设置共用的纯分类规则和类型；uniquePresetName/uniquePresetNames 仅在相同 Fast 标记内为重复名称补序号，保留ID、完整选择与显式已有编号，遵守256字节名称上限；手动分组优先于手动厂家，再回退系列自动识别与未分类；路由前缀不代表厂家，同名不同ID仍为独立模型。
- `styles.css`：模型矩阵、Fast按钮、独立分隔线与电流动效、原位切换目录、自然换行的内凹标签及编辑删除控件；使用容器语义颜色适配明暗与黑色主题，不绘制外层材质。积木仅以中性背景区分常用状态，没有对勾、图钉、计数或强调色。

顺序复用后台 modelOrder；只更新当前操作的偏好，保留旧常用、收藏、自定义组、手动厂家和暂不可用模型记录。expandedGroups仍兼容保存，快切不再依赖组内折叠状态。分组管理继续在Web设置“功能与交互 → 模型快切 → 模型分组”，不在快切增加分类编辑入口。

目录中的推理矩阵保留100–560px名称列宽；实际宽度按视口与可用档位夹紧，不覆盖偏好。Fast 与思考档位位于矩阵表头；列宽支持指针、方向键和 Esc 取消。闪电只切换Fast，禁用遵守目标与能力状态；开启时360ms自下向上填充充电；充满后先固化实心填充，保持至切换结果确认，再接续340ms SVG电流（145ms向下揭示），结束后仅在实际回读为Fast时保留实心；关闭立即恢复空心。动画与串行业务请求同时开始，失败、打开目录、拖动或卸载取消动画；减少动态效果直接显示实际状态，无充电或电流。动画清理时底层填充直接跟随真实状态，不依赖phase更新，防止收尾空心闪帧。Fast沿用18px OpenAI图标和28px按钮盒；预设栏的编辑、添加、目录统一18px图形和32px点击区。实心状态同时核对当前模型Fast能力与实际speed；标准或不支持Fast的模型保持空心。不支持Fast仍可调宽；拖动无蓝色焦点框，键盘聚焦通过细线加亮表示。无水平分隔线。贴边宽度仍由独立标记及420px名称预算决定，高度按实际名称列宽与换行测量，完整容纳常用模型和预设。拖动期间暂停原生尺寸测量，松手后再适配高度，宽度及贴边锚点保持。仅超过屏幕可用高度或在受限主界面中时，模型与预设共用列表滚动区；额度、测速和操作底栏保持可见，不将矩阵单独压成滚动框。

目录按钮与编辑、添加位于同一组，18px 图形、32px 点击区。打开目录后在原内容区显示可用 CLI 和当前 CLI 模型；模型积木以中性色区分已固定状态，点击加入/取消目录固定，不删除另外保存的完整预设。推理矩阵默认折叠。目录刷新、关闭放入已有标题槽；Escape 和外部点击关闭，键盘关闭恢复四点按钮焦点。目录、固定区分别滚动；切换目录不写入配置。

收藏区复用原presets；无外层背景框，仅独立标签通过中性内阴影呈现凹槽。只有Fast预设带实心闪电，标准预设不占图标位。标签名称后直接显示预设已保存的思考等级，与矩阵沿用相同写法；等级和Fast同时进入无障碍名称，悬停显示实际模型及完整配置，改名输入旁也保留等级和闪电。旧预设直接读取selection，不改写名称、ID或配置；空等级不编造默认值，明确none显示None，暂不可用时仍保留已存等级并禁止应用。普通模式单击应用完整选择；末尾铅笔切换统一编辑模式，所有标签左上角出现28px删除叉号，此时点击标签只进入原位改名，不调用模型。再次点铅笔或Esc退出编辑。删除按钮与标签是独立兄弟控件，失败保留预设和草稿。末尾书签图标捕获当前完整模型/强度/速度，直接以模型名追加独立预设，不弹出命名或确认表单；失败显示错误且不伪造新标签；新增和改名按当前完整列表核对名称与 Fast 标记；有无闪电可同名，同一标记内重名补2、3等序号，允许同一模型及同一配置保存多份预设，不按模型ID去重；输入框不使用原生JavaScript prompt，支持Enter保存、Esc取消与IME保护。改名与兼容旧新增草稿的 ID、名称、选择和creating同步写入Reading.modelPresetDraft；清空也同步删除，卸载/owner交接后恢复原选择。编辑模式通过原Reading.modelTools交接。标签独立自然换行，底栏统一容纳可选测速与额度/操作，空间不足时按组换行，不另设预设滚动条。

既有名称中的“ · ”来源后缀在矩阵中分行弱化；重名模型在积木中保留完整ID以区分。能力与官方菜单匹配仍在ui/codex/model.js，身份校验/串行操作/持久化仍在src/model_control.rs；窗口与原生几何由surfaces负责。

内置系列规则覆盖OpenAI、Anthropic、Google、DeepSeek、阿里云、智谱、月之暗面、xAI、MiniMax、阶跃星辰、腾讯、Meta、Mistral、百度、字节跳动、小米、Amazon、Cohere、Microsoft和NVIDIA；不枚举模型能力，未接入厂家不生成空组。

添加预设复用OpenAI书签图标，使用32px按钮和18px图形。

横向阅读恢复在表头与列宽测量后执行；初始临时宽度夹紧不能覆盖交接的滚动位置，后续几何更新继续恢复至可达位置。用户滚轮、指针、触摸或键盘操作接管后，以实际滚动为准，不反复拉回旧位置。

模型预设保留原有内凹标签、背景和选中状态；下一步快捷指令的下划线样式独立调整，不同步修改模型预设。

预设下方底栏左侧显示Codex剩余额度，支持5小时和周两个实际窗口，只有周额度时只显示周；缺失或过期不伪造百分比。使用中性色、数字等宽，额度和可选测速使用正文0.875倍（最小14px）的状态字号，跟随内容字号；操作图标仍为18px；文字行框与18px图标下边缘对齐，保留32px点击区；底栏距预设24px，收藏区不再叠加下方padding，使用外壳原有底部留白；调整位置时同时核对原生整窗坐标，不能用内容坐标代替屏幕实际位移；showUsage默认开启，可从模型快切设置关闭。额度变化不影响模型选择修订号或预设。

ModelView提供可选ReactNode footer插槽，位于底栏额度右侧；左侧顺序为周额度、5小时额度、可选测速，三个操作图标保持右对齐，未传入时图标位置保持稳定。底栏使用独立model-status-row样式，不与原有错误提示model-footer混用。模型视图不导入测速组件，组合层负责插入；投影中的可选tokenMeter不参与选择修订、保存或预设。

额度、测速及预设/目录操作组成不参与列表滚动的底栏，模型与预设在剩余高度内独立滚动；空间充足时底栏紧随内容，不把空白插在列表与读数之间。目录打开时底栏随收藏视图隐藏并禁止聚焦，预设编辑仍支持从内容或底栏按 Esc 退出。窄/矮容器验收同时检查初次打开与滚动后的读数和操作可见性，不能仅以“滚动后可以访问”通过。
