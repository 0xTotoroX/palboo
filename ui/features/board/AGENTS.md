# ui/features/board/ — 独立任务看板

> L2 | 父级：[AGENTS.md](../AGENTS.md)

由通用功能容器或 ui/surfaces/desktop/legacy-board.tsx 挂载，复用注入任务客户端，不依赖设置视图或宿主聊天。设置按displayMode选择看板/清单，共用原任务身份、全局顺序、分组和同步状态；看板默认待办、进行中、完成三组，名称修改和新增本地分组统一在设置页操作；卡片以标题为主，按需显示优先级与截止日期、组内创建，悬停或键盘聚焦显示垃圾桶，点击直接本地删除；触屏保持可见，点击标题打开右侧任务详情。旧归档记录在完成组保留，可拖回未完成组；旧 waiting 显示为待办且不改原值。

- [api.ts](api.ts)：任务类型、字段格式与可注入认证客户端（默认客户端延迟导入，不读取宿主令牌）；本地编辑串行，回读保存后的修订才解锁下一次编辑，旧响应不得覆盖新状态；显示开关已保存后的独立窗口错误，不回退任务修订；读取失败在重连成功后清除，保存失败独立保留至下次操作。
- [app.tsx](app.tsx)：与承载形式无关的动态分组、组内快速创建和按需搜索（搜索与清单加号复用功能标题操作槽，搜索以标题行内的输入区替换操作图标，不占正文；搜索与添加互斥，加号和搜索图标可再次点击收回；收回保留添加草稿，保存或Esc取消才清空；旧独立页回退原有工具槽，任务区独立滚动）；按displayMode挂载checklist或看板；看板按已保存viewMode选择合并标签或完全展开；合并始终只展示选中组，展开在680px以上并列、以下按内容自然行高纵向显示全部组，短视口不压缩行高造成组间遮挡，均可滚动；标签也是放置目标，切换接续草稿。
- `search.tsx`：标题槽内联搜索、共享图标、无框输入和关闭；搜索图标同时是收回按钮，空查询外部失焦调用dismissEmpty且不回抢焦点；操作槽与外层工具容器共同按可用宽度收缩，保留键盘焦点及跨承载草稿；不在正文增加搜索行。
- [card.tsx](card.tsx)：标题卡片、悬停删除与列放置区，直接处理浏览器 drag/drop 事件以兼容 Shadow DOM；最近卡片接收排序，列/标签接收跨组移动，列内顺序只存本地。
- [recovery.tsx](recovery.tsx)：仅冲突或远端缺失时显示行内处理入口，沿用原快照校验与恢复确认；普通编辑由 details.tsx 处理。
- [styles.css](styles.css)：响应式多列、统一圆角与间距，卡片和操作使用独立内容字号（默认 15px）、辅助状态至少 14px；独立页默认明暗主题及高对比、焦点和减少动态效果；嵌入工具栏透明，内容跟随承载材质。

- `checklist.tsx`：无阶段分组的平铺清单，保留原任务顺序；完成即时划线，保存成功才擦除/补位，失败保留原行；锁定保存时其他任务文字保持可读，删除仍按原悬停/键盘显隐；图标进入完成记录，只用左侧勾选圆圈恢复同一任务快照，保留原分组、远端及字段。快速添加由标题加号主动展开对齐的无底板输入行，空输入失焦调用dismissEmpty，非空时行首图标变为可点击的保存勾，Enter同样提交；输入文字用正文色，保存或取消后收回，详情/异常处理共用原组件；完成及删除成功只在用户没有转去其他控件时接续键盘焦点，末项优先回搜索或标题操作；减少动态效果、交接和销毁回收动效。

[PROTOCOL]: 文件或职责变化时同步本文与父级地图。

BoardView 保存搜索查询与显式开合状态、阶段、横向阅读位置、快速新建草稿及 editor 任务详情草稿；窗口交接保留草稿，locked 禁用任务操作。删除带 expectedTask 防止误删已更新的任务；后台只移除本地任务并记住远端身份，不删除 Apple 提醒事项。

Board 的可选 poll 默认为 true，真实任务视图沿用轮询；纯内存设置预览显式关闭轮询，读写仅交给传入的示例适配器，不回落到业务 API。

搜索、新增、删除和异常图标使用shared/icons/react，共用工作台的18px公开SVG目录；卡片删除点击区读取共享28px变量，容器及业务事件不变。

- `details.tsx`：标题/备注/优先级/截止日期编辑，复用原字段及0–9历史优先级；显式保存、关闭保留草稿，原任务快照改变时阻止覆盖并确认载入。同步开启时说明本地字段边界；标题与保存/返回固定在可见区，字段区独立滚动；180ms 抽屉动效尊重减少动态效果。

组件通过共享 data-intrinsic-width 声明清单的不折行自然宽度或看板920×620阅读预算；贴边承载由 workspace/mount 统一有界测量并请求详情表单自然高度；workspace/content 使用 edge 提供的可见矩形约束 dialog，采用不透明主题色避免文字穿透，有限屏幕内可滚动访问所有字段和保存。看板数据与详情草稿仍由原逻辑管理。

搜索及清单新建输入用data-editing声明当前是否有文字或正在输入法组字；false允许承载在鼠标移出后失焦并收回空输入，其他编辑器默认保留焦点保护。业务组件只处理标准失焦，不监听贴边原生事件。

清单的待办、完成记录与有效搜索无结果分别显示一条居中状态文字；添加输入可见时隐藏对应空态，不叠加操作说明。searching只传递查询状态，不改变任务存储。
