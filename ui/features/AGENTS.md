# ui/features/ — 功能内容

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

六种功能共用内容实现，只消费业务投影和受限操作。任务拖放、建议预览及模型选择属于功能；外层窗口、位置、分栏、主题与交接由 surfaces 管理。任务保存和提醒事项同步保留在 Rust，必须读取或操作 Codex DOM 的逻辑保留在 codex。

- [board/AGENTS.md](board/AGENTS.md)：卡片、组内创建、悬停删除、同步异常处理与跨组拖动。
- [outline/AGENTS.md](outline/AGENTS.md)：大纲列表、编号对齐及定位操作。
- [next/AGENTS.md](next/AGENTS.md)：建议列表、预览与点击规则。
- [model/AGENTS.md](model/AGENTS.md)：模型矩阵、预设和选择操作。
- `content.tsx`：固定六种功能的内容组合与业务命令适配；接收受限传输和可选顶栏操作位置，保持身份校验，草稿直接追加且不发送。
- `projected.tsx`：大纲/下一步的 React 投影适配，复用各自 view.js，保留预览及滚动状态；不解析宿主 DOM；空状态撑满剩余内容区并居中；名称由容器标签显示，内容区不重复绘制小标题；刷新操作通过 portal 放入容器顶部槽，业务校验仍归功能。
- `content.css`：大纲、建议与快捷词的共用内容样式、焦点及内容动效；状态提示共用正文0.875倍（最小14px）/500字重及中性颜色，加载共用18px圆环和文字动效，减少动态效果时停止；不绘制容器材质。

[PROTOCOL]: 结构、职责或接口变化时更新本文；父级描述受影响时同步父级地图。

- `terminology.tsx`：第五功能的术语积木、当前聊天/收藏/已掌握过滤，点击积木锚定共用贴字浮层，复用当前聊天只读字体/缩放快照；动作复用 owner 校验，默认点击只选择术语；jumpOnClick 开启时额外发送带术语编号和当前 context 的 locate 操作，错误沿用容器反馈，不写主聊天。

terminology 内容字号继承共享 feature-session；独立窗口中的点击浮卡直接消费后台 appearance 字体快照，不能用独立窗口默认字体代替宿主。

下一步的快捷指令由next/quick-prompts管理展示和临时草稿；content通过owner保护的quick-prompts action保存列表及expectedRevision，projected只适配回调与禁用状态。更新回读只合并当前投影的设置，不恢复旧聊天快照。

- [token-meter/AGENTS.md](token-meter/AGENTS.md)：独立可插拔测速读数；组合层通过ModelView可选footer接入，不参与模型操作或持久化。

- `bots/view.tsx`：Palboo 的 Grok Bot 选择与当前聊天调用状态；后台提供动态名单、已保存侧栏结构与最新消息摘要；按共享 botGroups 顺序呈现并过滤隐藏项，置顶组不显示标题，其他分组保留名称，简介只在设置中展示；最近消息默认不渲染，顶部唯一文字按钮切换至集中消息视图，按可见Bot顺序展示各自名称与最近消息；返回按钮恢复Bot列表，刷新保留主动打开、重新挂载默认收起，不新增持久开关或删除上游内容。选择、追问、查看进度及停止请求均经 owner 保护后填入 Codex 主输入框，无独立输入框。
- `bots/style.css`：继承容器语义颜色与字号的 Bot 入口、状态和动作样式；头像统一圆形与倾斜白色眼睛，保留真实颜色，未知颜色回退中性灰。

Bot 状态集中在头像和右下角徽章，取消下方图标行；徽章按异常、其他聊天占用、未读、已停止的优先级最多显示一个，分别使用警示、链接、圆点、方块。未读只采用已观察到的上游字段，不从完成状态推测，也不新增已读写回。运行中使用双眼动效，正常完成后不保留完成徽章。进度/追问/停止只在悬停整行或键盘聚焦时于行右侧显现，无悬停设备保留操作可达；预留操作位置，显隐不挤动名称。状态说明只在悬停入口或聚焦时显示，保留读屏名称和不可用入口的键盘说明，原生禁用与身份校验不变。分组内按可用宽度自然排列一列/两列/多列，Bot行不放消息按钮或箭头，顶部消息入口右对齐，独立消息视图自然换行；手动同步时刷新按钮通过headerActions放在标题旁，自动模式隐藏；未观察到调用时不重复显示空状态文案。几何由 bots-view 和 features-e2e 的真实渲染断言覆盖。

- `bots/avatar.tsx`：统一绘制圆形与倾斜白色眼睛，只同步应用颜色，忽略形状字段；工作状态用自有双眼同步眨眼、回复完成单次眨眼，默认静止。接收一个可选徽章，使用共享警示/链接图形及圆点/方块几何；10/14px徽章是头像装饰，不改变操作图标18px/点击区28px约定。通过可见性观察和页面可见性暂停离屏/隐藏动画，卸载清理监听，减少动态效果时静止并保留无障碍说明和适用徽章。未知颜色使用中性灰，不加载远端图片或复制官方动画。

Bot 目录异常、过期、空名单或缺少可输入聊天按优先级只显示一条提示；目标恢复即移除提示，仍按原身份和过期状态禁用动作。术语识别进行中或失败时不叠加空列表提示。

所有功能通过共享 i18n/useLocale 渲染产品文案；切换语言保留业务挂载与临时草稿。模型厂家分类、功能和标签ID不翻译；看板默认列标题仅在保存内容仍等于原默认标题时翻译，自定义列与任务内容保持原样。
