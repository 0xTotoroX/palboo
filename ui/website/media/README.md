# 品牌素材

`palboo-opening.mp4` 为 2026-10-20 用户确认的 v3 原片：6.8 秒，1200×620，30fps，无音轨。保持原画面、时序和浅色背景，未重新绘制或裁切。

`palboo-opening.source.html` 是同版自包含 SVG / CSS / JS 源文件，仅供维护与重建参考，不进入网站运行包。字形为 SVG 路径，无外部字体或网络资源。原预览控件不嵌入网站。

网站实际加载 `palboo-opening.svg`（从同版源文件原样提取）及 `../brand-poses.js`（保留原几何、曲线和时序，仅改为容器内查询并移除独立预览的控制栏依赖）。React 从0秒播放完整6.8秒序列，包含 PALB 打字、双 O 形变、眨眼与腮红；点击头像重播，离屏/后台暂停，播放结束停止计时。首个桌面滚动位移即完成原姿态，接续同一个 SVG 沿弧线落入左栏入口；停滚保持，反向沿原路返回。点击移动中或落定后的头像回到开场并从0秒重播，不绘制单独的刷新按钮。窄屏仍完整播放开场但不运输，减少动态效果直接显示终帧。原片时间轴与关键帧保持可独立核对。播放结束、页面未运输时，网站的 `brand-gaze.ts` 可在原父组上叠加鼠标视线位移；重播/运输/离屏/后台与减少动态效果恢复原位，不改本目录素材或单眼姿态。MP4 和原预览页面仅作来源参考，不进入运行包。
