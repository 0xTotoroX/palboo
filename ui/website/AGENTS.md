# website/ — 独立产品介绍页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

沿用根 DESIGN_SYSTEM.md 的品牌、主题与功能图标；这是独立静态页面，不进入设置页或 App 内嵌产物。演示仅使用组件内示例数据，不连接 Palboo、Codex 或模型服务，不读取用户业务配置。正式版本下载入口必须与实际发布状态一致。

按已确认的品牌定位、下一步、大纲与术语、看板、形态、辅助工具和安装顺序阅读，不加顶部菜单、分节编号、装饰性标签、重复功能选择器或说明卡片。品牌开场直接嵌入已确认的原版，不另造近似动画；建模演示复用设置页现有场景与窗口移动，不另画简化方框。

- `index.html` / `main.tsx`：中文静态入口、React 挂载与本模块样式。
- `app.tsx`：串联完整内容主线、可操作看板与辅助工具、兼容和安装条件；主题控制位于页脚，没有导航菜单。
- `story.tsx`：品牌双眼落到左栏入口；桌面宽度下同一工作台随三段正文切换下一步/大纲/术语；设备与副屏按滚动往返。窄屏、短窗口与减少动态效果使用逐段可操作内容；切换模式保留组件状态和焦点，编辑或拖动时暂停自动换章。
- `scroll-motion.ts`：原生滚动、尺寸与媒体偏好驱动的进度；被动监听，每帧合并，闲置无持续循环，卸载回收。
- `brand-opening.tsx`：原版 SVG 的滚动控制；字母/双 O 形变跟随滚动且可逆，到达双眼后按原速度眨眼，离屏/隐藏停止，静态模式使用最终帧。
- `brand-poses.js`：2026-10-20 确认的 v3 原始几何与 6.8 秒时间轴，仅改为容器内查询并剥离原预览控制栏依赖。
- `media/`：原 SVG、MP4 和自包含编辑源，来源与用途见 README；网站只加载 SVG，不打包原预览页面或 MP4。
- `demos.tsx`：统一作品集示例；建议与 Bot 咨询追加草稿、大纲实际定位、术语收藏/掌握、看板真实拖动与键盘移动、模型示例选择、提示优化/还原。设备复用 settings 的 `LayoutPreviewScene`；直接滚动时输入几何，手动切换沿用 `useDemoJourney` 并从当前滚动帧接续；任务提交、取消和状态移动恢复键盘焦点。所有状态只在本页内存中。
- `styles.css` / `story.css` / `demo-content.css`：内容层级、品牌与设备滚动场景、详细功能示例；设备模型 CSS 由原 settings 文件导入，字体与控件适配窄屏，保持原动画两套主题色。
- `vite.config.ts`：本机开发/预览与 `target/site/` 静态输出；相对资源路径，无业务 API 代理。输出 `LICENSES.txt` 附自有 GPL 与 React / React DOM / Scheduler / 控件图标 MIT 原文，文件缺失即失败。

不引入新图标库、字体、动画或 3D 依赖。共享 `brand.tsx` 保持静态。验证使用合成浏览器 DOM、几何、原版关键时刻比对、滚动往返、拖放与动画状态；不截图、不触碰真实 App。素材检查以最终静态产物为准，不将私有导出脚本、路径、会话或验收材料带入网站。
