# website/ — 独立产品介绍页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

沿用根 DESIGN_SYSTEM.md 的品牌、主题与功能图标；独立静态页面，不进入设置页或 App 产物。演示复用 App 功能组件、设置页布局预览与原样式，输入仅为合成作品集数据，操作保存在本页内存；不连接宿主、模型或真实配置。下载指向实际 GitHub Release 页面。

页面由显示器开场、一个功能展台、紧凑下载区组成。展台按设置页顺序展示大纲、下一步、常用语、术语释义、任务看板、模型切换、Grok Bot、阅读与网页、提示词优化、兼容集成。桌面左侧固定功能目录，右侧一次显示一个真实设置预览；原生上下滚动同步切页，点击目录直接定位，方向键及 Home/End 可操作。只用一层外框，标题28px、导语15px、功能正文14px；开场共用16px排版。不增加顶部菜单、章节编号、装饰标签或额外连线路径。

品牌开场保留已确认的原版6.8秒动画。首屏保持品牌／文案居中在上、完整显示器在下，以 Studio Display 正面造型为参考，屏幕16:9；不分发 Apple 图片或标识。原生滚动先收起支架并接近同一个实时屏幕，再遍历侧栏、页面浮层、副屏、右侧贴边和顶部刘海，随后展示哑光、磨砂、液态 Regular／Clear 和纯黑。开场滚动距离3.5个视口，不给每种状态单独堆叠整屏；双眼沿原路径进入左栏入口，保留44px重播点击区。手动操作暂停自动演示，继续滚轮或触屏恢复；输入和拖动期间保持当前视图。排列及字号保持手动选择，位置巡览不重写排列。窄屏、矮窗口或减少动态效果使用自然排版与手动控制。

功能展台总高3.4个视口，不让各功能分别占用整屏。窄屏或矮窗口改为横向功能栏和普通文档流，保留正常字号与实际控件；只横向滚动目录，不因点选移动整页。

同一双眼贯穿后续滚动：从屏幕左栏跳进现有材质背景字标，背景随材质巡览逐渐加深；离开材质区时先向左、再下落到当前功能目录的左侧留白，不替换功能图标或覆盖预览。切页短跳从当前画面位置接续，反向滚动沿原路回去，不绘制路径线。最后落回下载区字标，停留2.2秒后展开为两个O；离开或后台取消停留，返回后重新落定。窄／矮屏及减少动态效果关闭跨区飞行，保留自然页面与页尾字标变化。飞行层不接收输入，闲置不轮询，不增加页面长度。

十个预览持续挂载，隐藏面板不可聚焦或操作，切换保留内存草稿、任务和收藏；离开术语页关闭浮卡。当前预览进入视野后只通过真实操作入口示范一次，指针、焦点、键盘或拖动永久接管该页。后台、切页、卸载和手动接管取消待执行演示；减少动态效果不自动播放。页面切换仅短距淡入，功能动画来自定位、展开、填入、优化及状态变化，不叠加描边框或阶段文案。
