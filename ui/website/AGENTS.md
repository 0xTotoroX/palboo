# website/ — 独立产品介绍页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

沿用根 DESIGN_SYSTEM.md 的品牌、主题与功能图标；这是独立静态页面，不进入设置页或 App 内嵌产物。演示仅使用组件内示例数据，不连接 Palboo、Codex 或模型服务，不读取用户业务配置。正式版本下载入口必须与实际发布状态一致。

按内容和布局组织单列阅读，不加顶部菜单、分节编号、装饰性标签、重复功能选择器或说明卡片。品牌开场直接嵌入已确认的原版，不另造近似动画；建模演示复用设置页现有场景与窗口移动，不另画简化方框。

- `index.html` / `main.tsx`：中文静态入口、React 挂载与本模块样式。
- `app.tsx`：原版开场 → 窗口模型 → 可操作工作台 → 安装入口，主题控制位于页脚；没有导航菜单。
- `brand-opening.tsx`：原版 SVG 的播放器；单次播放、暂停/重播、离屏/隐藏暂停，减少动态效果停在最终双眼。
- `brand-poses.js`：2026-10-20 确认的 v3 原始几何与 6.8 秒时间轴，仅改为容器内查询并剥离原预览控制栏依赖。
- `media/`：原 SVG、MP4 和自包含编辑源，来源与用途见 README；网站只加载 SVG，不打包原预览页面或 MP4。
- `demos.tsx`：六项功能及四种窗口位置的示例；功能图标为唯一选择入口。直接复用 settings 的 `LayoutPreviewScene`、设备表面 CSS 和 `useDemoJourney`；所有交互与草稿仅在本页内存中。
- `styles.css` / `demo-content.css`：单列页面与详细功能示例；设备模型 CSS 由原 settings 文件导入，字体与控件适配窄屏，保持原动画两套主题色。
- `vite.config.ts`：本机开发/预览与 `target/site/` 静态输出；相对资源路径，无业务 API 代理。输出 `LICENSES.txt` 附自有 GPL 与 React / React DOM / Scheduler / 控件图标 MIT 原文，文件缺失即失败。

不引入新图标库、字体、动画或 3D 依赖。共享 `brand.tsx` 保持静态。验证使用合成浏览器 DOM、几何、原版关键时刻比对与动画状态；不截图、不触碰真实 App。素材检查以最终静态产物为准，不将私有导出脚本、路径、会话或验收材料带入网站。
