# website/ — 独立产品介绍页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

沿用根 DESIGN_SYSTEM.md 的品牌、主题与功能图标；这是独立静态页面，不进入设置页或 App 内嵌产物。演示仅使用组件内示例数据，不连接 Palboo、Codex 或模型服务，不读取用户业务配置。正式版本下载入口必须与实际发布状态一致。

按品牌定位、下一步、大纲与术语、看板、模型/测速/提示优化/Bot、位置与布局、材质、连接和安装顺序阅读，不加顶部菜单、分节编号、装饰性标签或重复功能选择器。功能细节放在对应示例旁，连接等次要细节按需展开。品牌开场直接嵌入已确认的完整原版；建模与材质直接复用设置页现有场景、编排和窗口动画。

- `index.html` / `main.tsx`：中文静态入口、React 挂载与本模块样式；仅开发服务的 `?preview=github-buttons` 动态加载按钮对比，正式构建不包含对比控件或模块。
- `app.tsx`：串联完整内容主线、可操作看板与辅助工具、兼容和安装条件；明暗实时跟随系统，无导航菜单和页脚。安装区以品牌/回到顶部与安装条件两列收束，窄屏纵向排列，不显示版本准备状态；回到顶部同时恢复键盘起点、保留示例状态，减少动态效果时立即返回。
- `github-link.tsx`：首屏 GitHub 发布页入口，默认官方 GitHub 标记加“下载”，细描边、无尾部箭头；保留文字、描边、实心三个对比预设。标记来自本地单个 SVG，不引入图标库依赖或预填尚未发布的 DMG 地址。
- `button-presets.tsx` / `button-presets.css`：开发专用对比页，在真实页面内以原生单选切换四种按钮；正式页面不显示选择器。
- `story.tsx`：首个滚动位移开始运送原版双眼，沿弧线缓缓落到左栏并显现工作台；点击头像回到开场重播，不显示独立刷新按钮，移动及落定时均保留44px点击范围；首个示例包含 Codex 标题栏、聊天目录、正文与输入区，桌面目标16:10。桌面宽度下同一工作台按实际正文标题位置切换下一步/大纲/术语。窄屏、短窗口与减少动态效果使用逐段可操作内容；切换模式保留组件状态和焦点，编辑、键盘操作或拖动时暂停自动换章，鼠标操作期间的焦点与布局自动滚动不换章，主动滚轮/触摸或外部点击恢复阅读；断点变化恢复未聚焦章节对应功能，并保持活动编辑器可见。阅读场景在 resize 当下保护当前焦点，避免晚到的媒体断点通知让滚动换章先替换正在操作的功能。
- `scroll-motion.ts`：原生滚动、尺寸与媒体偏好驱动的进度，以及显式重播时同步回到起点；被动监听，每帧合并，闲置无持续循环，卸载回收。
- `brand-opening.tsx`：原版 SVG 从0秒播放至6.8秒，保留打字、吐双O、滚动、变眼睛、眨眼与腮红，响应头像重播；离屏或后台暂停，结束停止计时。桌面开始滚动时完成原姿态并交接位置，不让字母飞向入口；减少动态效果直接终帧。运输继续使用同一SVG，不在落点换图。
- `brand-poses.js`：2026-10-20 确认的 v3 原始几何与 6.8 秒时间轴，仅改为容器内查询并剥离原预览控制栏依赖。
- `media/`：原品牌 SVG、MP4 和自包含编辑源，以及 GitHub 标记与原始许可；来源与用途见 README，网站只加载 SVG，不打包原预览页面或 MP4。
- `demos.tsx`：统一作品集示例；建议与 Bot 咨询追加草稿、大纲定位、术语收藏/掌握、看板拖动与键盘移动、提示优化/还原。模型快切复用 settings 的 ModelPreview 与真实 ModelView，以具体 Codex 模型名称、能力档位、Fast、预设及明确标注的示例额度演示；聊天测速复用 TokenMeterView 的本地状态示例。任务提交、取消和状态移动恢复键盘焦点。所有状态只在本页内存中。
- `workspace-demo.tsx` / `workspace-demo.css`：直接复用完整 LayoutPreview、原设置页窗口移动与真实布局控制器；展示侧栏让位、浮层覆盖、桌面副屏、四边贴边/刘海、功能切换和上下/左右/标签编排。材质比较复用设置页品牌背景与哑光/磨砂/液态 Regular/Clear 样本，不再维护网站专用运输时间线；所有覆盖仅改演示内存，聚焦输入立即落定窗口以保留可编辑位置。
- `styles.css` / `story.css` / `demo-content.css`：内容层级、品牌与阅读滚动场景、功能示例；设备、材质、工作台和模型样式由原模块导入，仅在网站作用域适配大小与颜色。
- `vite.config.ts`：本机开发/预览与 `target/site/` 静态输出；相对资源路径，无业务 API 代理。输出 `LICENSES.txt` 附自有 GPL 与 React / React DOM / Scheduler / 控件图标 / Octicons MIT 原文及 GitHub 标记商标说明，文件缺失即失败。

不引入新图标库、字体、动画或 3D 依赖。共享 `brand.tsx` 保持静态。验证使用合成浏览器 DOM、几何、原版关键时刻比对、滚动往返、拖放与动画状态；不截图、不触碰真实 App。素材检查以最终静态产物为准，不将私有导出脚本、路径、会话或验收材料带入网站。
