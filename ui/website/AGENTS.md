# website/ — 独立产品介绍页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

沿用根 DESIGN_SYSTEM.md 的品牌、主题与功能图标；这是独立静态页面，不进入设置页或 App 内嵌产物。演示直接复用 App 功能组件及原样式，以本页内存适配器提供示例数据，不连接 Palboo、Codex 或模型服务，不读取用户业务配置。正式版本下载入口必须与实际发布状态一致。

按品牌开场与位置/布局、材质与外观、下一步、大纲与术语、看板、模型/测速/提示优化/Bot、连接和安装顺序阅读，不加顶部菜单、分节编号、装饰性标签或重复功能选择器。功能细节放在对应示例旁，连接等次要细节按需展开。品牌开场直接嵌入已确认的完整原版；建模与材质直接复用设置页现有场景、编排和窗口动画。

开场、布局与材质属于同一个滚动场景，只有一个持续挂载的 LayoutPreview/工作台。保留原双眼落点与布局停留后，工作台随滚动放大并移到材质背景中央；设备外框淡出，原品牌背景显现。控件先退出布局组再显示材质组，反向回到原位置且不重置草稿、字号或编排。键盘进入控制组立即切换取景，编辑时暂停；窄屏、短窗口与减少动态效果直接显示两组控件，操作时在同一预览中切换。预览关闭滚动锚定，防止内部 SVG 几何变化挪走按下中的按钮。

桌面原生滚动依次遍历上下/左右/标签、侧栏/浮层/副屏/四边贴边及六个功能，再进入哑光/磨砂/液态 Regular/Clear/纯黑样本；最后回到侧栏再放大材质，保持空间连续。后续看板、模型档位/Fast、测速、提示优化与 Bot 咨询按各自滚动距离推进。每段保留阅读距离，反向可回看，不捕获滚轮、不运行自动播放计时器。点击、输入、键盘操作或拖动暂停当前段；保留当前状态，离开编辑并主动滚动后接续。访客草稿始终优先于自动示例。整体网页浅深主题仍只由手动按钮切换。

- `index.html` / `main.tsx`：英文静态入口和双语无脚本说明、React 挂载与本模块样式；仅开发服务的 `?preview=github-buttons` 动态加载按钮对比，正式构建不包含对比控件或模块。
- `app.tsx`：串联完整内容主线、可操作看板与辅助工具、兼容和安装条件；以图标单击切换浅色或深色，无导航菜单和页脚。安装区以品牌/回到顶部与安装条件两列收束，窄屏纵向排列，不显示版本准备状态；回到顶部同时恢复键盘起点、保留示例状态，减少动态效果时立即返回。
- `github-link.tsx`：首屏 GitHub 发布页入口，默认官方 GitHub 标记加“下载”，细描边、无尾部箭头；保留文字、描边、实心三个对比预设。标记来自本地单个 SVG，不引入图标库依赖或预填尚未发布的 DMG 地址。
- `button-presets.tsx` / `button-presets.css`：开发专用对比页，在真实页面内以原生单选切换四种按钮；正式页面不显示选择器。
- `story.tsx`：首个滚动位移开始运送原版双眼，沿弧线缓缓落到左栏并显现工作台；点击头像回到开场重播，不显示独立刷新按钮，移动及落定时均保留44px点击范围；首个示例直接嵌入设置页的 Codex/副屏模型；原 SVG 双眼落到同一模型左栏，滚动继续放大该场景后再露出位置、排列与字号控制，不另画简化窗口或在下方重复一套布局演示。桌面宽度下同一工作台按实际正文标题位置切换下一步/大纲/术语。窄屏、短窗口与减少动态效果使用逐段可操作内容；切换模式保留组件状态和焦点，编辑、键盘操作或拖动时暂停自动换章，鼠标操作期间的焦点与布局自动滚动不换章，主动滚轮/触摸或外部点击恢复阅读；断点变化恢复未聚焦章节对应功能，并保持活动编辑器可见。阅读场景在 resize 当下保护当前焦点，避免晚到的媒体断点通知让滚动换章先替换正在操作的功能。
- `scroll-motion.ts`：原生滚动、尺寸与媒体偏好驱动的进度，以及显式重播时同步回到起点；被动监听，每帧合并，闲置无持续循环，卸载回收。
- `scroll-tour.tsx`：网站专用的布局/材质有序停留点与 ScrollDemo；复用原生进度，在离散状态变化时驱动隔离演示，手动接管时冻结当前状态。按实际内容高度居中，内容超出视口或窄屏/短窗口/减少动态效果时自然排版，不强制固定；没有外部服务或配置写入。
- `brand-opening.tsx`：原版 SVG 从0秒播放至6.8秒，保留打字、吐双O、滚动、变眼睛、眨眼与腮红，响应头像重播；离屏或后台暂停，结束停止计时。桌面开始滚动时完成原姿态并交接位置，不让字母飞向入口；减少动态效果直接终帧。运输继续使用同一SVG，不在落点换图。
- `brand-poses.js`：2026-10-20 确认的 v3 原始几何与 6.8 秒时间轴，仅改为容器内查询并剥离原预览控制栏依赖。
- `media/`：原品牌 SVG、MP4 和自包含编辑源，以及 GitHub 标记与原始许可；来源与用途见 README，网站只加载 SVG，不打包原预览页面或 MP4。
- `demos.tsx`：作品集聊天框架、功能切换与示例草稿；模型复用 ModelPreview/ModelView，测速复用 TokenMeterView，思考/工具/等待时保留最近测速并说明状态。功能节点持续挂载，切换保留草稿和选择。
- `product-demos.tsx`：直接挂载 ProjectedContent 的下一步/大纲、TerminologyView、Board 和 BotsView；建议追加草稿、大纲定位示例段落、术语收藏/掌握、任务拖动/详情编辑、Bot 头像状态及单徽章/悬停操作/顶部最近消息均使用产品实现。只接入本地操作适配器；Bot 操作仅填入示例草稿。
- `demo-state.ts`：完整类型的合成投影及有修订校验的内存任务适配器；未知命令拒绝，不回落到业务接口。示例字段随语言翻译，访客编辑保留。
- `demo-surface.tsx`：以 Shadow DOM 挂载实际组件和原 CSS，隔离网站样式重置；只适配容器尺寸、网站语义色与工作台材质颜色。
- `demo-focus.ts`：识别 Shadow DOM 内的真实焦点与独立术语卡片所属演示，保护编辑和响应式切换；不改产品事件处理。
- `prompt-demo.tsx`：真实 installPromptEnhancer 接入本页输入框与确定性示例回复，支持优化/取消/还原及草稿比较保护；滚动通过同一个按钮演示，手动编辑优先，不调用模型。
- `workspace-demo.tsx` / `workspace-demo.css`：直接复用完整 LayoutPreview、原设置页窗口移动与真实布局控制器；位置演示在开场中单份挂载，展示侧栏让位、浮层覆盖、桌面副屏、四边贴边/刘海、功能切换和上下/左右/标签编排；通过可选 renderFeature 插槽将真实组件挂入稳定内容节点，renderControls 将位置与排列/字号集中在模型下方的两行，贴边方向只随当前形式出现；窄屏位置改为下拉，排列与字号自然换行，不重复说明或显示添加示例入口。正文字号跟随/比例/自定通过共享 typographyStyle 实际作用于示例。滚动初段控件隐藏且场景 inert，镜头靠近后显现并可操作；600px以下聚焦工作台保持文字可读，不裁掉半个设备；重置同时还原字号和贴边位置。材质比较复用设置页品牌背景与哑光/磨砂/液态 Regular/Clear 样本，不再维护网站专用运输时间线；所有覆盖仅改演示内存，聚焦输入立即落定窗口以保留可编辑位置。
- `styles.css` / `story.css` / `demo-content.css`：内容层级、品牌与阅读滚动场景、功能示例；设备、材质、工作台和模型样式由原模块导入，仅在网站作用域适配大小与颜色。
