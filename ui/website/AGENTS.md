# website/ — 独立产品介绍页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

沿用根 DESIGN_SYSTEM.md 的品牌、主题与功能图标；独立静态页面，不进入设置页或 App 产物。演示复用 App 功能组件、设置页布局预览与原样式，输入仅为合成作品集数据，操作保存在本页内存；不连接宿主、模型或真实配置。下载指向实际 GitHub Release 页面。

页面由短品牌开场、阅读／写作／协作三个组合场景、紧凑下载区组成。不增加顶部菜单、分节编号、装饰标签或重复功能选择器。每个场景只用一个外框；标题30–48px、导语16px、功能正文14px。开场共用默认排版（16px）。阅读左上角的兼容集成直接复用设置页 Agent 菜单，以显式合成快照关闭本机轮询；选择仅改变演示来源名称并保留草稿。阅读给聊天主体空间，下一步和大纲共享侧栏，术语贴近正文；写作让常用语与模型、提示词优化围绕同一草稿；协作给看板宽区、Bot 窄栏。手机纵排，保留可读字号与实际控件，不整窗缩成截图。内部正文、标题操作和滚动区域需一起验收，不能只检查外框。

品牌开场保留已确认的原版6.8秒动画。桌面原生滚动将同一双眼送到复用模型的左栏入口，再衔接同一工作台的材质背景；总滚动距离2.9个视口，不再逐一巡视位置、排列、功能或材质。位置、排列、字号及材质仍可手动选择，滚动不重写这些选择。窄屏、短窗口和减少动态效果使用自然排版，保留一份 LayoutPreview 与操作状态。

三个组合场景持续挂载，不随滚动切换或隐藏功能。进入视野后轻量演示一次：大纲定位与建议填入、常用语展开／填入／优化、任务移动与 Bot 回复。任何点击、输入、键盘操作或拖动都永久接管当前场景，继续滚动不会恢复自动写入。减少动态效果不自动播放；后台、卸载和手动接管清理计时器及未完成文字飞行。动效由实际内容变化表达，不覆盖连线路径、描边框或额外阶段文案。

- `index.html` / `main.tsx`：英文静态入口、双语无脚本说明及 React 挂载；开发服务的 `?preview=github-buttons` 动态加载按钮对比，正式构建不包含对比控件。
- `app.tsx`：串联开场、三个场景和下载区；平台与连接条件按需展开。回到顶部恢复键盘起点，保留演示草稿；减少动态效果立即返回。
- `scenes.tsx` / `scenes.css`：组合场景的空间分配、共用标题操作槽与一遍入场演示。写作只挂载一份 PromptPreview，常用语追加到同一输入框；手动编辑和异步优化沿用产品的草稿比较保护。看板在宽屏横排，窄桌面可内部横滚，手机使用真实纵排。头部不重复工具栏，底部测速与操作保持可达。
- `story.tsx` / `story.css`：原双眼从首个滚动位移开始落到真实模型入口，点击可回顶部重播；始终保留44px点击范围。镜头接近后显现布局控制，再自然过渡到材质；键盘操作稳定当前取景，编辑时不挪动输入框。
- `scroll-motion.ts`：原生滚动、尺寸与媒体偏好驱动进度；被动监听、逐帧合并，闲置无持续循环。
- `scroll-tour.tsx`：仅维护开场距离常量；功能场景不再预留固定滚动距离。
- `brand-opening.tsx` / `brand-poses.js`：原版SVG几何及6.8秒时间轴；保留打字、吐双O、滚动、变眼睛、眨眼与腮红。离屏／后台暂停，结束停止；减少动态效果直接终帧。落点不换图。
- `brand-gaze.ts`：结束后有界追视，重播、运输、离屏、后台或减少动态效果清理位移；不改原时间轴。
- `media/`：原品牌SVG、MP4和编辑源，以及GitHub标记与许可；来源见README。页面只加载SVG，不打包原预览页或MP4。
- `workspace-demo.tsx` / `workspace-demo.css`：复用设置页 LayoutPreview、窗口移动和布局控制器；位置／排列／字号／材质操作仅改内存。renderFeature 贯通真实组件的 headerActions；稳定挂载保留各功能状态。600px以下聚焦工作台。材质为网页近似，原生液态边界明确保留。
- `demos.tsx`：共享功能名称、双眼和带唯一标签的本地输入框，不再维护可切换的第二套聊天演示。
- `product-demos.tsx`：真实 ProjectedContent、TerminologyView 与 Board 的合成数据适配器；建议刷新和追加、常用语编辑／展开／名称切换、大纲定位、术语收藏／掌握、任务拖动／编辑均沿用产品行为。headerActions 复用所属场景标题槽。
- `model-demo.tsx`：真实 ModelView 与 TokenMeterView，合成目录、额度与预设；模型档位由示例能力限定，实际支持取决于接入环境。保留厂家目录、预设编辑、Fast 和最近测速，不另占章节。
- `bot-demo.tsx`：真实 BotsView 和原CSS；协作场景用三个紧凑角色，开场保留完整示例状态。咨询／追问／停止仅填入本页草稿，最近消息复用标题操作；可选详细模式保留有限状态重播和分组。
- `demo-state.ts`：重导出 shared/demo-state 的合成投影与内存任务适配器。网站看板采用 expanded；不传本地用户快照。
- `demo-surface.tsx`：Shadow DOM 挂载真实组件及原CSS，只适配尺寸、语义色和正文滚动；功能头部操作通过显式槽回到现有标题行。
- `demo-focus.ts`：辨认 Shadow DOM 与术语卡片的真实焦点，保护开场编辑位置。
- `narrative.tsx`：可取消的文字飞入输入框与短暂反馈；取消后不执行迟到写入，减少动态效果直接落定。
- `../settings/codex-host-preview.tsx` / `.css`：复用兼容集成菜单，显式 example 不读取宿主；身份图标及其来源、LGPL/GPL 原文随站点署名输出。
- `../settings/prompt-preview.tsx`：共用真实优化／取消／还原控件和确定性回复；可选外部草稿供网站组合场景使用，设置页默认仍独立持有预览输入，不调用模型。
- `styles.css` / `demo-content.css` / `showcases.css` / `chapters.css`：语义主题、真实内容外部排版、短反馈与紧凑下载区，不重画产品控件。
- `github-link.tsx`：真实发布页链接，默认本地官方GitHub SVG加“下载”；保留开发对比预设，不预填未发布DMG地址。
- `button-presets.tsx` / `button-presets.css`：开发专用按钮对比，正式页面隐藏。
- `locale.ts` / `language.tsx` / `locales/en.js`：网站独立语言，URL优先，其次 palboo-site-language，最后系统；切换保留访客输入及功能状态。
- `theme.tsx`：浅／深单击切换，默认浅色，只保存 palboo-site-theme；不跟随系统或修改宿主。术语卡片订阅同一主题。
- `vite.config.ts`：本机开发／预览与 `target/site/` 静态输出；无业务API代理。产物带 GPL 及第三方原许可、GitHub标记说明，缺失即失败。

不新增图标库、字体、动画或3D依赖。验证覆盖组合操作、草稿和状态保护、网络隔离、品牌原始几何／关键时刻、中英文、明暗、窄／矮屏、键盘及减少动态效果，合成截图不触碰真实App。发布通过 `.github/workflows/site.yml` 显式选择已审核提交，默认只构建，publish才部署；本地预览不代表上线。
