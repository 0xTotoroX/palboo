# website/ — 独立产品介绍页

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

沿用根 DESIGN_SYSTEM.md 的品牌、主题与功能图标；这是独立静态页面，不进入设置页或 App 内嵌产物。演示仅使用组件内示例数据，不连接 Palboo、Codex 或模型服务，不读取用户业务配置。正式版本下载入口必须与实际发布状态一致，不把未发布的安装包描述为可下载。

- `index.html`：中文入口、页面元信息及无脚本回退。
- `main.tsx`：React 挂载与本模块样式入口。
- `app.tsx`：介绍页阅读顺序、独立主题、一次性品牌开场、功能与安装入口。
- `demos.tsx`：六项功能及四种窗口形态的可交互示例；所有状态仅在本页内存中。
- `styles.css`：设置页同源设计语言、响应布局及可中断窗口切换；尊重减少动态效果。
- `vite.config.ts`：独立开发 / 预览服务与 `target/site/` 静态输出；相对资源地址支持子目录托管，无业务 API 代理。输出附带自有 GPL 与 React / React DOM / Scheduler / 控件图标 MIT 原文的 `LICENSES.txt`，源文件缺失即构建失败。

不引入新的图标库、字体、动画或 3D 依赖。共享 `brand.tsx` 保持静态，OO → 双眼动画仅在本页作用域内运行一次，允许手动重播。验证使用合成浏览器 DOM、几何与动画状态；不截图、不触碰真实 App。
