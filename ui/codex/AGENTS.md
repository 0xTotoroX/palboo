# ui/codex/ — Codex 页面适配

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

- `composer-actions.js`：提示词优化、还原和侧聊所有操作共用右侧语音/发送挂载、尺寸与页面级互斥锁；令牌化释放防止迟到结果解开新操作，订阅即时刷新禁用态。保持 CodexHost 模型/Agent/原生动作相邻，不写宿主样式。
- `side-chat.js`：唯一右侧 Side Chat 的“带回原主聊天 / 转为独立主聊天”双入口；完整操作带上未发送文字，历史操作排除当前草稿。接力快照使用逐轮问答 Markdown；本地父聊天优先追加原生文本卡片，原正文/引用保持不动，能力缺失或云端回退文字追加并拒绝破坏复杂目标草稿。本地全量转正保留 ID，历史建立新分支，云端填入新聊天交接草稿。所有路径不发送、共享锁和30秒期限，保留空行并去重；来源/目标/内容变化、流式/IME或不支持的源草稿停止，失败保留内存恢复。全宽侧栏由本次收起后仍校验保留的标签及草稿；尺寸及激活观察保证页面重显，销毁清理入口。
- `side-chat-attachment.js`：核验本地 main ComposerScope、模式及原生 TSib/Dgwo 能力后创建宿主管理的 Markdown 文件并注册“粘贴的文本”卡片，不改正文、不读原始会话文件或上传云端。SHA-256 文件名去重；前后核验草稿/聊天回调、提交代次、附件列表与提交状态，兼容原生 Immer 更新器。失败/迟到仅移除本次路径及文件，仍被引用的文件保留；写入失败不再回退第二次插入。
- `side-chat-replies.js`：与大纲复用原生回答操作行，挂载带回/独立两个“截至此处”图标；复用 context.conversationTurnElements 识别本地 contents 与云端普通 div，排除重复 Markdown 子单元。点击捕获回答节点及完整内容签名，回答替换或身份歧义拒绝，不改大纲的选择与跟随状态。
- `side-chat-history.js`：本地分页读取所有 turns 及每轮完整 items，云端从原生当前分支读取 rendered turns；截至所选轮次的前缀排除后续文字，未知/重复/未完成边界、重复 cursor、不完整页与2M文字上限拒绝，不静默截断。无需历史消息挂载于 DOM。
- `side-chat-native.js`：已加载宿主模块和当前提交 React 树的兼容边界；nativeScope 支持按谓词区分 ThreadScope 与 ComposerScope，验证父子聊天、tab 实例、host 与账号/别名后将本地卡片写入委托附件适配。父聊天操作仅收起面板；本地转正通过原生标题确认、关闭标签、必要时清理会话内存缓存及官方导航解除 sideConversation，目标 scope 回读确认，不删除 forkSource 或修改宿主包/存储。历史分支复用原生 fork helper 及指定截止轮，回读新分支完整文字核对范围、补齐标题后才导航；失败保留源聊天。云端新建 hideFromHistory:false 的主聊天，保留源记忆偏好，未知接口拒绝。

- `codex-host-preview.js`：认证设置请求按需执行的只读表达式，复用v2探针与当前唯一输入目标，读取已挂载Agent菜单的名称、顺序/主组/更多组、可用与可添加状态、当前选择；未知协议、歧义目标和菜单/探针不同步时拒绝展示。会话锁定不影响Agent就绪状态。无菜单点击、安装、写入、独立定时器或聊天正文采集。

model.js 的全页 DOM 观察器只在官方菜单事务期间启用，完成、失败和销毁时断开；共享输入目标识别仍保留给提示词优化等调用方。独立模型功能关闭后后台不再回读官方菜单状态。

读取和操作 Codex 页面，保留必须在浏览器环境执行的逻辑。context/composer 不依赖功能视图；outline/next 协調现有业务状态与受限后台请求，呈现交给 ui/features。

- `plugin-tab.js`：官方 Palboo 插件标签适配；右键设置显式 follow=false 只手动打开，原 Dev 自动跟随试验仍默认停用；身份复用 context 的主聊天标记识别，新版“新标签页”经 contextmenu 打开插件菜单而非创建浏览器页，错误带阶段；兼容统一任务标签条和“显示标签页”入口，先恢复官方分屏，聊天身份稳定750ms后才跟随；空面板走“新建标签页→更多工具”，菜单采用可取消的 Enter 激活，过滤隐藏/离屏/被遮挡同名控件；等待切换中的短暂无身份，并在插件选中后再次确认分屏与连续两次选中状态；手动成功后只在主聊天身份变化时恢复，唯一实际可命中的控件、限时等待、身份复核、切换取消后继续跟随、单聊天失败停止重复尝试及销毁取消；不读正文、不走私有 IPC 或浏览器替代。
- `page-context.js`：记录最近操作的主聊天或标签页，主聊天兼容 data-app-shell-main-content-layout 容器，识别模态窗口及已验证的独立聊天容器，供停靠与输入目标校验共用；普通非模态注释/编辑浮层不改变停靠目标。
- `context.js`：mainChatSessionId 复用现有明确聊天标记并拒绝多主聊天歧义，不受阅读锁定影响；聊天/回答/输入目标识别、上下文与流式状态；conversationTurnElements 统一筛选本地/云端带角色的轮次，排除重复正文子单元；latestConversationTurn 统一按 DOM 轮次顺序读取最新身份，latestConversationTurnIdentity 在生成期间只维护身份而不读取正文，ID 仅作相等校验，缓存只在当前聊天记录已确认的前序 ID，最新卸载时不回退旧轮次，无共同轮次的未知窗口须到聊天末尾再接纳；忙碌检查先筛选停止按钮，输入候选循环复用本轮前景快照，不跨调用缓存聊天归属；集中选择器与正文解析，角色优先读取 data-conversation-role，旧标签忽略隐藏打印名称，完整采集相邻用户问题；terminologyExchange 按同一顺序提供最近三轮已完成问答，新回答生成期间排除当前轮，避免仅分析收尾短句而丢失正在讨论的概念。
- `composer.js`：输入框操作与发送就绪重试；草稿读取保留裸文本/块节点边界、连续及首尾空行，只忽略末尾 BR 光标占位，不裁剪原始文本换行；每次发送重试核对调用意图及聊天身份。
- `typography.js`：读取正文排版、UI 字体变量及祖先有效 CSS zoom；只输出样式快照供 Palboo 共用，优先使用已识别的聊天来源，不读取或保存正文。
- `appearance.js`：只读适配 Codex 字体、主题与内容边界；readSettingsAppearance 采样界面字体、页面语义色、控件状态、连续曲率/圆角/间距/开关尺寸、阴影与公共动效变量及减少动态效果供设置页消费，缺少背景/前景时不发布。导航/分组/页面标题的字号、行高、字重与字距按角色采集，包含中性选中背景和分组边框；字体额外读取字形特性、可变轴、样式/伸缩与光学尺寸；输入边框、普通按钮交互与分段选项独立采集；菜单尺寸优先 app-menu 覆盖，保留通用变量回退。读取宿主已发布的双色主题时使用隐藏自有节点承接现有样式并立即回收，相同签名复用结果，不切换宿主主题或焦点；优先直接语义色，避免根节点兼容别名跨模式继承。
- `association.js`：跟随/锁定/改锁来源的受限操作；来源文字与菜单暂时隐藏，保留状态与失联反馈，不保存容器布局。
- `outline.js`：协调本地大纲刷新、回复操作区入口和真实聊天定位；目录入口复用当前回答操作栏及相邻原生按钮/图标样式，与侧聊双操作共存；新回答生成期间保留已完成回答的入口，当前生成轮次等待完成，操作栏缺失时等待挂载，重挂载时移回正确行；自动跟随、回复入口及手选的新旧判定共用 context.latestConversationTurn，手选最新仍自动跟随且不显示返回按钮，手选历史按当前聊天及轮次保留，切换聊天或停用时清理；点击重新核验聊天/回答身份、内容版本、锚点次序及完整原文，重挂载不按截断标签猜匹配；不依赖下一步，列表由 features/outline 渲染。
- `outline-parser.js`：只读扫描当前回答的全部 Markdown 正文块；有正式标题时只用正式标题，否则识别编号/独立加粗伪标题；两类标题均缺失时按长度选择自然段边界并为后续组保留块，最多六条原文摘录导航，按分组完整内容去重，同首句/同截断前缀标签作区分；列表/表格与短引导句同组，代码不作标签。保留编号混排与层级，去重后返回原文锚点，不调用模型或持久化正文。
- `next.js`：建议生成协调、最近 32 次结果的内存缓存、普通/快捷词直接追加草稿且不发送；缓存校验完整问答、聊天和生成配置，停用或配置变化清空。
- `model.js`：观察关联的官方 model/list 能力，优先识别输入区/祖先的稳定聊天身份，引用注释仅作为无权威身份时的回退；无消息区的新聊天以明确的官方输入区实例建立临时目标，不持久化、不继承路由或引用身份，输入区替换或身份建立使旧操作失效；提供宿主可见性/焦点，经官方菜单执行并回读；支持独立子菜单、内联选项、simple/advanced同根视图、显式模型后的推理滑块及Fast复选项/速度飞出菜单；从菜单内读取模型名、从可访问标签读取速度，关闭后记录稳定缓存；高级目录直接交叉核对当前模型、触发器思考档位和活动组件内唯一 Fast 语义标记，不为读取或选模型强制返回简洁视图；隐藏状态只读，不匹配另一隐藏视图或点击隐藏控件，缺失、冲突和重复时拒绝猜测；仅调整强度/速度需要控件时尝试官方返回路径。显式操作的有界无正文阶段仅保留在本机诊断，不拼入用户报错；先记录菜单归属再解析，失败清理自身菜单；旧目标、冲突、官方控件禁用或能力未知时拒绝切换；生成状态不单独阻塞；有界事务可取消，部分完成明确报告。
- `LICENSE.model-deck`：Model Deck 原始 MIT 许可，分发保留署名。
- [runtime/AGENTS.md](runtime/AGENTS.md)：注入集成入口、分域状态、设置同步与窗口投影。

context 管理跟随/锁定与唯一来源重绑，锁定失联不回退其他来源。page-context/context 排除自有功能根，避免将任务编辑框识别成聊天；输入框在消息区旁边时，仅扩展到包含唯一聊天的最近容器。模型能力未知、目标冲突或官方控件禁用时拒绝切换。

旧模型专用 UI 已退出；模型功能由 features/model 提供，/model-control 兼容 URL 转至设置页。model.js 仍是实际官方菜单适配器，不是可删除的旧窗口。

模型目录缺失时，状态回读通过现有 electronBridge 向本机发送只读 model/list，不依赖菜单重新广播或重启宿主；并发共享一次读取，3.5秒总超时，失败后由后续状态回读按30秒间隔重试，无独立轮询。显式刷新可立即重试并回读菜单当前配置，仍受11秒事务截止限制；被动读取不打开菜单、不改焦点或模型。目录按请求身份及hostId校验，最多10页/1000项完整收齐后更新，旧响应不覆盖新目录；账号/连接变化清空目录及在途请求，取消/停用/销毁只放弃自身请求。同一document内重装接续已验证的能力字段，不继承当前选择、请求关联或修订号；新document重新获取，不持久化能力缓存。无electronBridge的旧宿主继续观察关联的官方消息。

[PROTOCOL]: 结构、职责或接口变化时更新本文；父级描述受影响时同步父级地图。

plugin-tab.js 的 openSettingsBrowser 仅接收本机 HTTP 地址，经当前聊天的可见新标签页与浏览器地址栏导航，并恢复分屏；目标变化、重复入口或缺少地址栏时报错，不降级到外部浏览器，不记录 URL 令牌。

内置浏览器打开前显式展开隐藏的标签栏；创建按钮排除 role=tab 的同名“新标签页”标签；新建后等待地址栏，不重复点击同一个 New tab。该浏览器适配与保留的插件实验同文件，但不依赖 MCP 或插件安装。

- `prompt-enhancement.js`：在已确认输入区工具栏挂载优化/取消/还原，与所有侧聊操作共用互斥锁，自己的取消保持可用；结束、取消、禁用及销毁即时释放，迟到请求不能解除新锁。复用composer原始文本读取与受控写入。仅保存当前操作的临时原文、DOM与签名；输入变化/IME/会话变化/销毁取消，迟到结果不可覆盖；复杂引用节点拒绝替换，错误行内展示。

model.js增加只读inputTarget()，复用唯一聊天身份与最近操作归属，不依赖模型能力/菜单触发器；已有snapshot/apply仍要求模型触发器。

提示词优化入口位于当前输入框右侧语音/发送操作同排，避开模型选择器的折行容器。按钮只显示PencilSparkle图标，与原生按钮同高；处理中为取消图标，完成后同一个按钮变为还原图标，回退后恢复优化，编辑后旧备份失效并恢复优化图标，无文字标签，提供双语title与aria-label。

codex-host.js通过上游版本化只读探针按输入框确认Agent与可选CLI列表；快切选项仅保留Codex、ready的CLI和当前选择，沿用上游顺序，未安装/未就绪候选不占位，菜单缺失回退探针时使用同一筛选；缺失/未知状态或未挂载外部模型控件时拒绝官方模型写入，不触发上游菜单；已挂载外部模型菜单（`[data-codexhost-model-control]`）时只读解析模型与思考档位并通过既有菜单项完成切换，未锁定的新会话可通过既有Agent菜单项直接切换CLI，已锁定会话可通过prepareHandoff提取当前对话与未发送草稿，由后台保存本地Markdown快照后触发宿主新聊天、切换目标CLI并预填交接块。model.js向selectAgent传入已校验的sourceTargetId；新聊天入口优先按来源ID匹配可见侧栏行（兼容宿主前缀），不借用其他选中项目，缺少来源行时先用唯一明确的 Codex 分组创建动作，再兼容 Recents 的任务入口；混合宿主的顶部“新聊天”属于 ChatGPT，不能用于 CLI 接力。Agent 控件查找止于当前输入区边界，不借用隐藏旧聊天；普通 ChatGPT 聊天明确提示切回 Codex，真实重复仍拒绝。等待新聊天时接受唯一新出现的官方草稿输入框或由锁定变为草稿的复用绑定，排除原有可见的其他输入框；有草稿时只向已绑定目标 CLI 的输入框追加，校验草稿与绑定未变化，其他 CLI 的草稿原样保留，不发送；跨CLI固定模型在切换后复核同一输入目标，再应用完整配置，第二步失败报告部分完成。cdp在model.js前安装，codexCatalog保持官方model/list目录隔离，提示词优化保留独立输入目标识别。

运行入口复用 context 的 chatRoot/findLatestAssistantMessage/findPreviousUserText 将只读问答交给独立术语模块，不增加另一套聊天身份识别。

prompt-enhancement接收isEnabled只读配置；关闭时移除按钮、取消请求并清空临时备份。CodexHost存在时加入原生语音/发送的内部包装，原生按钮直属时放其后，保持上游模型/Agent/原生动作的相邻约束；无布局变化不重复搬动或写入宿主样式。

typography.createTypographyTracker 通过 lifecycle 提供的当前聊天/唯一输入框取样；左侧标题选择器集中在本文件。按 body/session/composer 缓存有效快照；连续相同且间隔至少200ms才发布，切换/隐藏不回落到 body 默认样式。无可用历史时16px系统字体。

- `next-drop.js`：接收推荐原生复制拖放，只接受当前关联输入框，复用 panelCommand 身份校验和只填入行为；中性轮廓/240ms释放反馈、减少动态效果静态反馈、取消及销毁清理，不提供纯文本回退。

- `model-usage.js`：通过宿主本机 account/rateLimits/read 只读获取 Codex 账号额度；按实际300/10080分钟窗口显示剩余百分比，优先codex桶，不借用其他模型额度。读取由快切状态驱动、每分钟限频，无独立轮询；账号变化/断连/停用清空，销毁回收，无凭据或额度持久化。

next.js追加草稿只补齐一处换行，复用已有末尾换行；保留用户有意留下的空行，不添加空段。openSettingsBrowser为10秒有界流程，恢复分屏后确认聊天，排除旧地址栏/旧标签，提交前复核身份及输入节点；只确认宿主接受地址提交，不等同页面加载成功。

context.chatBusy 在当前聊天及其唯一关联输入区识别停止控件（中英文名称与已知图标），覆盖正文旁的输入区，不跨聊天取忙碌状态；next 在实际发起生成前再次检查。

- `token-meter-state.js`：当前聊天的流式测速状态机；tokenx 轻量多语言估算，3秒/8192个UTF-16单元/31桶上限，按轮次隔离官方累计与最近调用；片段结束或隐藏时结算最近有效速度，跨本聊天的思考/工具/轮次保留数值，换聊天时清空，不读取历史正文。
- `token-meter.js`：独立的无UI采集器，按宿主与聊天过滤通知；read(expectedThreadId)校验目标并以最多2Hz缓存数值投影，复用宿主状态回读及交互跟随目标，无独立计时器；隐藏不收集文字；按已校验模型ID与Fast状态在内存保留最多32份最近有效速度，切换聊天或新聊天继续显示，官方计数与阶段仍按聊天重置。旧轮次只更新原模型，未知选择不归属；关闭/断连/销毁清空。

- `bots-state.js`：只接收本机 grokbot.call_tool 的 MCP 事件，按 host/thread/turn/item 保存最多128条元数据；忽略正文和 earlierReplies，完成事件必须匹配已观察的开始身份并去重，名单或账号切换后的迟到结果不能认领新 Bot；兼容 turnId/turn.id，检查失败和 busy 不解除已确认任务占用，终态校验会话身份。
- `bots.js`：Palboo 的 Grok Bot 宿主适配；复用唯一输入目标，以临时 token 和真实 DOM 身份校验后追加草稿、聚焦但不发送；聚焦后再次核对目标，重复点击不重复追加且光标回到草稿末尾。通过setCatalog接收后台动态名单与已验证侧栏投影；账号变化同时作废旧输入 token，隐藏项拒绝填入；动作校验Bot ID、名称和名单修订，追问/查进度/停止请求只填入主聊天。有本聊天调用时，追问仅接受当前 key 对应的 finished/interrupted 状态；没有记录时，可凭新鲜目录中该 Bot 的已有回复填入简短追问，不宣称该回复来自本聊天。其他聊天占用仍拒绝，旧 key 不得降级到目录回复，不把可选 sessionId 当作必需能力。关闭后清理监听和记录，无独立轮询，不调用 BDK。

插件名称匹配兼容 `Palboo` 和旧 `PALBOO`，同时出现时仍按重复入口拒绝；不修改已安装插件身份。

- `terminology-import.js`：仅在有术语任务时接住用户主动发送，核对唯一当前输入框、聊天、草稿及连接身份后追加本机任务路径，并继续原发送；不替换引用节点、不单独启动 Agent。编辑、换聊天及销毁释放未追加任务；已追加的可见草稿重试不重复附加。

独立注入的 codex-host.js 与 model.js 保持经典脚本，无 ESM 导入；显示文案通过已挂载 `__companionFloatingPanel.translate` 读取共享语言，尚未挂载时回退中文并保留插值。该只读接口不改变 Agent 身份、模型ID、探针协议或外部环境。

page-context 共用 contentKind/hostPageKind/hostPageAllowed，区分官方单标记的新聊天/Dots，不读取正文。model 支持编辑器或外层任一官方标记，继续拒绝多个输入框、身份冲突和过期操作；inputTarget 附带节点身份 token 与可选 selection；测速优先使用已核对选择，未核对时只读当前官方触发器中的模型及已识别 Fast 图标（未知图标不猜测），不打开菜单或升级为可写配置。next 的空聊天快捷词复用此目标，已有草稿只追加；延迟发送校验同一节点且不重绑定。普通推荐仍校验回答上下文。

常用语以 quickPromptsEnabled 独立于 Stepwise 运行；contextMatches 的 answer=false 仅用于常用语聊天身份校验，保留运行代次、锁定来源与聊天身份约束，不要求回答哈希。普通建议继续验证回答身份。异步发送同时核对原聊天/输入目标及预设内容，已有草稿只追加。

字体 tracker 的 snapshot 按 body/session/composer 分别防抖缓存并只读投影 sources；resolved 按目标窗口偏好只采对应来源，复用既有生命周期、不新增轮询。字体自定义仅作用于自有节点。

plugin-tab 的 openWebsiteBrowser 与 openSettingsBrowser 共用可见宿主地址栏流程；前者允许无内嵌凭据的 HTTP(S)，设置包装器仍只接受本机 HTTP。只提交刚创建并唯一识别的标签，不覆盖已有页面；返回 submitted 不代表网页加载完成。
