# app_update/ — 手动完整 App 更新

> L2 | 父级：[src/AGENTS.md](../AGENTS.md)

`../app_update.rs` 负责显式 HTTP 请求、模式修订/锁、私有 worker 请求、后台正常退出及恢复。成功只递增共享模式修订并保留原配置；集成暂停或手动断开不自动连接。安装前已校验的目标与后台身份必须仍一致；模式交接、安装器和启动入口共用 `app-mode.lock`。

- `release.rs`：固定公开仓库的稳定 Release、精确 DMG 名称/附件身份、受限 HTTPS 重定向、有界响应/下载与 SHA-256 校验；不读 GitHub 凭据，不接受前端下载 URL。显式忽略用例只访问公开 GitHub 并下载到临时目录，普通测试不联网。
- `install.rs`：App 身份与可写性、包内路径/清单/签名/可运行性、只读挂载及临时副本；同卷 `RENAME_SWAP` 原子交换，失败反向交换，不先删除现有 App。成功保留一份前版，仅清理本更新器有归属标记且未混入其他文件的更早副本。
- `dock.rs`：通过系统 Foundation 保持当前安装已有 Dock 项的 GUID/顺序，将本次目标或备份路径重新绑定到原位置并清除旧文件书签；私有备份、并发前值和回读校验，其他应用及其他 Palboo 安装不变，未固定时不新增。测试只写随机隔离偏好域，不触碰真实 Dock。
- `tests.rs`：临时 App + 合成后台协议 + 真实文件交换，覆盖正常更新、原连接恢复、断开保留、启动失败和重连失败回滚，不访问真实应用、数据或宿主。`install.rs` 的显式忽略用例接受 `PALBOO_UPDATE_TEST_DMG`，只校验/准备指定本地 DMG，绝不激活。

分发只有当前稳定版自己的完整 DMG 可安装；源码补丁保留说明入口。安装请求只携带 Release/附件 ID、版本及模式修订；worker 重新读取官方发布信息。下载/包验证完成和进度页接手之前不关闭后台。新的后台先以断开状态启动，再恢复原已连接目标；启动尚未发布运行信息时仅能回收本次持有的子进程。异常时保留旧 App 实际所在路径，不把“旧包已回位、后台未恢复”误报为完整恢复。
