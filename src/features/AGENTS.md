# features/ — 共享主界面

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `main_surface.rs`：由 features.rs 调用，读取并迁移主界面偏好，管理唯一桌面子进程与 main lease；全部非贴边功能统一位置，来源快照和全部目标 ready 后整组提交，失败恢复原归属并保留关闭状态；最后一个桌面成员交出后同步回收旧窗口/租约，避免快速重开复用正在退出的进程。按主形式保存经过校验的递归分栏布局，读取兼容旧单轴分组；支持六功能独立成行及可选 collapsed（缺省false且不写出），跨层拒绝重复功能、无效比例和过深布局，布局类型提供语义相等比较用于并发校验，兼容 JSON 整数与浮点比例；提供共享尺寸、置顶持久化、统一 Dev 设置入口和锚点请求，不管理任务或模型业务。

[PROTOCOL]: 职责或接口变化时更新本文，并检查父级地图。

features.rs负责主界面接管后的缺失成员补登记，只补开关已开启且无条目的outline/next/board；旧桌面/旧看板窗口存在、整组交接中或当前系统不支持目标形式时暂不迁移。已有条目的owner/open/布局不改。task_command复用原任务服务，打开看板与功能开关统一接入这一策略。

terms 使用同一主窗口与功能owner，业务读取/操作转 terminology，locate 沿用 owner 与交接互斥校验；有私有词库时为已管理主界面补登记，不重开已关闭条目。

bots 使用现有主界面与 owner，独立 grokbotEnabled 开关控制；已有设置可恢复缺失成员但不重开已关闭条目。业务读取和填入由 features.rs::bot_view 委托当前 CDP 的 __palbooBots，连接变化拒绝投影，所有动作保持主聊天输入。

- `bots.rs`：本机 BDK 名单传输与 OS 文件监听；过滤账号槽/roster/侧栏分组/ui-agent-refs 事件，以原有可见读取节奏消费变化，60秒健康兜底；手动模式回收 watcher，首次/显式刷新/动作时读取；停止时回收缓存；校验账号、修订、stale布尔值及 Bot 身份字段，保留有效的过期目录供展示，过期资料仍禁止填入操作，异常目录显示同步失败；可选 sidebar 校验版本、组 ID、置顶位置与可见身份的唯一完整覆盖，兼容旧目录；不消费回复游标。
