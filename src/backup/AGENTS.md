# backup/ — 本地配置备份与恢复

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `mod.rs`：共享协调器；认证 API 的 status/export/preview/copy/apply/undo。预览十分钟有效，目标变化拒绝应用，完成结果匹配预览身份；当前或活动目标通过其服务停止监听活动并重新载入，不共享可变数据目录。
- `archive.rs`：版本1归档，逐模块版本、文件及拆分字段白名单，128 MB上限；含密钥强制 age 密码加密，限制解密计算量及原件总量。
- `snapshot.rs`：配置、外观、布局、贴边、模型、阅读、任务、术语的完整持久投影；个人数据、密钥与机器目录分开。稳定双读，沿用旧布局／模型／材质兼容转换，阻止链接与路径越界，预览仅返回字段路径，不返回值。
- `validate.rs`：按现有领域校验恢复文件，旧任务schema继续交给原迁移、未知schema拒绝；保留当前连接、程序路径、暂停意愿及Jev本机同意，不继承会话/瞬态状态；恢复数据后暂停提醒事项同步、使未完成术语任务可手动重试，递增偏好修订。
- `storage.rs`：私有恢复点、事务日志、逐文件原子写入及目录同步；中断回退，撤销前检查后续编辑，撤销同样暂停外部任务并刷新修订。服务锁保护停止状态的目标，不合并或覆盖其他环境的数据目录。
- `targets.rs`：仅发现统一启动器已登记的正式数据及Git工作树的Dev数据；校验版本，不切换启动模式或来源。
- `cli.rs`：本地服务客户端，文件写入不覆盖既有输出；密码只从文件或stdin读取，应用需显式confirm。
- `reader_preferences.rs`：独立阅读器的宽度与侧栏固定偏好；严格字段白名单、串行写入，纳入reading模块。
- `tests.rs`：合成数据的选择性保留、加密/篡改、版本、并发保护、回退与路径边界。

不归档运行凭据、锁、日志、生成缓存、聊天身份、外部笔记正文或供应商登录。自动恢复点是本机0600文件（可能含原密钥），不是对外导出归档；本轮不提供云端或自动双向同步。
